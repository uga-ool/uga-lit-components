Instructor Card Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Displays an instructor profile card with photo and name. Automatically detects the course from the URL and finds people on the classlist whose role is Banner Instructor, Instructor, or Teaching Assistant (in that order when multiple appear). Works for students, instructors, and admins.

Use username to pin a specific account by Brightspace username (comma-separated for several). Use multiple to show more than one card when several instructors match.

Properties

Property Type Description
username string Optional. Brightspace username(s), comma-separated. Filters to those accounts after role detection. Pins are allowed only for Banner Instructor, Instructor, or Teaching Assistant (or when the classlist hides the role label—empty—if the user is not clearly a Student/Learner). Case-insensitive.
multiple boolean Optional. Default false. When true, shows one card per matched instructor. When false, only the first match is shown.

Examples:

  • <uga-instructor-card username="jdoe"></uga-instructor-card> — single named instructor
  • <uga-instructor-card username="jdoe,jsmith" multiple></uga-instructor-card> — two cards, display order follows the list
  • <uga-instructor-card multiple></uga-instructor-card> — one card per Banner Instructor, Instructor, or Teaching Assistant in the course
<uga-instructor-card></uga-instructor-card> <!-- Specific instructor(s) --> <uga-instructor-card username="jdoe"></uga-instructor-card> <!-- All instructors (multiple cards) --> <uga-instructor-card multiple></uga-instructor-card> <!-- Two named instructors --> <uga-instructor-card username="jdoe,jsmith" multiple></uga-instructor-card>
