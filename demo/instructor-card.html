Instructor Card Component

A profile card showing an instructor’s photo and name, read from the course classlist.

This component reads the current eLC course through the Valence API, so it only fills in when the page is viewed inside eLC. It detects the course from the URL and matches people whose role is Banner Instructor, Instructor, or Teaching Assistant, in that order. Add the component bundle before </body> — see Setup & Usage.

Basic usage

With no attributes it shows the first matching instructor for the current course. This is the usual case, and it needs no course or person configured.

<uga-instructor-card></uga-instructor-card>

A specific person

Pass a Brightspace username to username to pin the card to one account, or a comma-separated list for several. Matching is case-insensitive. A pin only works for someone already holding an instructor or teaching assistant role, so it cannot be used to show a student.

<uga-instructor-card username="jdoe"></uga-instructor-card>
<uga-instructor-card username="jdoe,jsmith" multiple></uga-instructor-card>

Several cards

Add multiple to show one card per matched instructor instead of just the first. With a username list, the display order follows the order you wrote.

<uga-instructor-card multiple></uga-instructor-card>

Attributes

uga-instructor-card attributes
Attribute Type Default Description
username string empty Brightspace username, or a comma-separated list, to pin the card to specific accounts. Case-insensitive. Applied after role detection, so only instructors and teaching assistants can be pinned.
multiple boolean false Show one card per matched instructor. Without it only the first match appears.
