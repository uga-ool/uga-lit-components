Course Analytics Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Local preview: This page loads /dist/js/uga-components.js when the hostname is localhost; in eLC, the same script tag should resolve to the production bundle at /shared/ugaonline/js/uga-components.js.

Overview

The <uga-course-analytics> component provides course-wide analytics that aggregate data from multiple sources (content views/completions, assignments, discussions, and quizzes) to show module-level consumption statistics and comparisons.

The embedding page should be hidden from students via eLC release conditions. This component does not perform its own role check.

Basic Usage

Embed the component in any eLC content page:

<uga-course-analytics></uga-course-analytics>

Live Example

Component Properties

Property Type Default Description
show-content-stats boolean true Show content view/completion statistics
show-assignments boolean true Show assignment submission statistics
show-discussions boolean true Show discussion participation statistics
group-by string 'module' Group statistics by 'module', 'topic', or 'all' (currently only 'module' is implemented)
compare-modules boolean true Enable module comparison view with visual indicators

Customized Example

Show only content and assignment statistics:

<uga-course-analytics
  show-content-stats="true"
  show-assignments="true"
  show-discussions="false"
  compare-modules="true">
</uga-course-analytics>

Data Sources

The component aggregates data from:

  • Content: Module/topic views and completions from eLC Content API
  • Assignments: Submission rates and scores from Dropbox API
  • Discussions: Post counts and participation from Discussion API
  • Objectives: Learning objectives count from Competencies API
  • Login History: Student logins in last 30 days (excludes admin/instructors)
  • Grades: Average final grade for students

The component automatically groups assignments and discussions by module based on their distribution across course modules. For more accurate module assignment, ensure your course content is properly organized with modules and topics.

Visual Indicators

The module comparison table includes color-coded indicators:

  • Green: Above average performance
  • Orange: Average or below average performance

Performance Considerations

The component makes multiple API calls to aggregate data across the course. For large courses with many modules, students, and activities, loading may take several seconds. The component includes:

  • Automatic caching of API responses (5-10 minute TTL)
  • Parallel API calls where possible
  • Error handling for missing or inaccessible data
  • Loading states during data fetch
