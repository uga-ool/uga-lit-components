Course Analytics Component

A summary of course activity: content statistics, assignment and discussion counts, and comparisons between modules.

This component reads the current eLC course through the Valence API, so it only fills in when the page is viewed inside eLC. It is aimed at instructors and designers reviewing how a course is put together. Add the component bundle before </body> — see Setup & Usage.

Basic usage

With no attributes it shows every panel, grouped by module. The course comes from the page URL.

<uga-course-analytics></uga-course-analytics>

The component makes a number of Valence calls to assemble its figures, so on a large course it takes a few seconds to fill in.

Choosing what to show

Each panel can be switched off. All three default to on, so you only need these attributes to remove something.

<uga-course-analytics show-discussions="false"></uga-course-analytics>
<uga-course-analytics show-assignments="false" show-discussions="false"></uga-course-analytics>

Grouping

group-by takes module, topic or all. Use topic for a per-item breakdown, or all for a single course-wide total. compare-modules adds the module-to-module comparison and is on by default.

<uga-course-analytics group-by="topic"></uga-course-analytics>
<uga-course-analytics group-by="all" compare-modules="false"></uga-course-analytics>

Attributes

uga-course-analytics attributes
Attribute Type Default Description
show-content-stats boolean true Show the content statistics panel.
show-assignments boolean true Show the assignments panel.
show-discussions boolean true Show the discussions panel.
group-by string module How figures are grouped: module, topic or all.
compare-modules boolean true Include the module-to-module comparison.
