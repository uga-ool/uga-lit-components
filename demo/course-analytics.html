Course Analytics Component

A summary of course activity: content statistics, assignment and discussion counts, and comparisons between modules.

This component reads the current eLC course through the Valence API, so it only fills in when the page is viewed inside eLC. It is aimed at instructors and designers reviewing how a course is put together. Add the component bundle before </body>.

This component is under review and its figures should not yet be used for decisions about students. group-by is not implemented, so grouping is always by module. The per-module assignment and discussion counts are placeholders rather than real attribution, because eLC does not tell us which module an assignment or discussion belongs to, and discussion participation is estimated from the post count. Content statistics and the course-wide totals are accurate.

Basic usage

With no attributes it shows every panel, grouped by module. The course comes from the page URL.

<uga-course-analytics></uga-course-analytics>

The component makes a number of Valence calls to assemble its figures, so on a large course it takes a few seconds to fill in.

Choosing what to show

Each panel can be switched off. All three default to on, so you only need these attributes to remove something.

<uga-course-analytics show-discussions="false"></uga-course-analytics>
<uga-course-analytics show-assignments="false" show-discussions="false"></uga-course-analytics>

Grouping

group-by is reserved and does nothing yet. The component always groups by module, whatever value you give it. compare-modules adds the module-to-module comparison and is on by default.

<uga-course-analytics compare-modules="false"></uga-course-analytics>

Attributes

uga-course-analytics attributes
Attribute Type Default Description
show-content-stats boolean true Show the content statistics panel.
show-assignments boolean true Show the assignments panel.
show-discussions boolean true Show the discussions panel.
group-by string module Reserved. Only module grouping is implemented; other values are accepted and ignored.
compare-modules boolean true Include the module-to-module comparison.
