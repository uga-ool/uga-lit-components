Callout Component

Semantic callouts for notes, tips, warnings, examples, and important reminders. The component renders an <aside> with an optional bold pseudo-label, so it adds no heading tags that would show up in a page table of contents.

Add the component bundle before </body>.

Types

Set type to one of note, important, tip, example, or warning. Each type has its own color and icon. An unrecognized value falls back to note.

<uga-callout type="note" label="Note" body="Use this section to provide extra context that supports the main content."></uga-callout>
<uga-callout type="important" label="Important" body="Complete the identity check before opening the exam in eLC."></uga-callout>
<uga-callout type="tip" label="Tip" body="Break long tasks into short numbered steps to improve completion rates."></uga-callout>
<uga-callout type="example" label="Example" body="Apply the formula to one sample problem before assigning practice work."></uga-callout>
<uga-callout type="warning" label="Warning" body="Do not upload screenshots of spreadsheets; submit the original file instead."></uga-callout>

Sizes

Set size to small, medium, large, or xlarge to change the spacing and text size. It defaults to medium.

<uga-callout type="note" size="small" label="Small" body="Compact spacing for a brief aside."></uga-callout>
<uga-callout type="note" size="medium" label="Medium" body="The default size."></uga-callout>
<uga-callout type="note" size="large" label="Large" body="More breathing room for a longer passage."></uga-callout>
<uga-callout type="note" size="xlarge" label="X-Large" body="Largest spacing and text size."></uga-callout>

Without a label

Omit label and the callout still renders semantic aside markup, just without the bold heading strip.

This callout omits label and still renders semantic aside markup.
<uga-callout type="note"> <p>This callout omits <code>label</code> and still renders semantic aside markup.</p> </uga-callout>

Rich body content

Use the body attribute for plain-text bodies, because plain text survives eLC HTML sanitization. For lists, links, or multiple paragraphs, put the content in the element instead of using body.

Check each of the following:

  • File is a PDF, not a screenshot.
  • Your name appears in the file name.
  • You have reviewed the rubric.
<uga-callout type="tip" label="Before you submit"> <p>Check each of the following:</p> <ul> <li>File is a PDF, not a screenshot.</li> <li>Your name appears in the file name.</li> <li>You have reviewed the <a href="#attributes">rubric</a>.</li> </ul> </uga-callout>

Nested callouts

Nest another <uga-callout> inside the element to place a worked example within a larger note.

<uga-callout type="note" label="Case Study Setup" body="For a 12% annual rate over 6 months, convert to the period rate before applying the formula."> <uga-callout type="example" label="Worked Example" body="Read the short scenario first, then work through the embedded example."></uga-callout> </uga-callout>

Linking to a callout

Give the element an id to link directly to it from elsewhere in the course, for example #exam-window.

<uga-callout id="exam-window" type="important" label="Exam Window" body="The exam opens Friday at 8:00 a.m. and closes Sunday at 11:59 p.m."></uga-callout>

Attributes

uga-callout attributes
Attribute Type Default Description
type string note One of note, important, tip, example, or warning. Unrecognized values fall back to note.
size string medium small, medium, large, or xlarge spacing and text size.
label string empty Bold heading text shown in the colored top strip. Omit it to render the callout with no strip.
body string empty Plain-text body in the lower section; survives eLC HTML sanitization. For lists, links, or multiple paragraphs, put the content inside the element instead.
