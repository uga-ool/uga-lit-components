Callout Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and examples.

Local preview: This page loads /dist/js/uga-components.js when the hostname is localhost (run npm run build first); in eLC, use /shared/ugaonline/js/uga-components.js. Callout corners use Design System util-radius-all-sm (requires base.css).

Semantic callouts for examples, notes, warnings, tips, and important reminders. This component renders as an <aside> with an optional bolded pseudo-label, so it avoids adding heading tags that could interfere with page TOCs.

Live Examples

<uga-callout type="note" size="small" label="Note (Small)" body="Use this section to provide extra context that supports the main content."></uga-callout> <uga-callout type="important" size="large" label="Important (Large)" body="Complete the identity check before opening the exam in eLC."></uga-callout> <uga-callout id="id-usage-callout" type="note" label="ID Usage Example" body="Link to this block with #id-usage-callout."></uga-callout>

Without Label

This callout omits label and still renders semantic aside markup.
<uga-callout type="note"> <p>This callout omits label.</p> </uga-callout>

Nested Callouts

eLC tip: Use the body attribute for plain-text bodies so content stays inside the box after sanitization; nest another <uga-callout> in the slot for the inner callout.

<uga-callout type="note" label="Case Study Setup" body="For a 12% annual rate over 6 months, convert to the period rate before applying the formula."> <uga-callout type="example" label="Worked Example" body="Read the short scenario first, then work through the embedded example."></uga-callout> </uga-callout>

Properties

Property Type Default Description
type string note One of note, important, tip, example, or warning.
label string (empty) Bold heading text shown in the colored top strip.
body string (empty) Plain-text body in the lower section; survives eLC HTML sanitization. For lists, links, or multiple paragraphs, use slot content instead.
size string medium small, medium, large, or xlarge spacing and text size.
