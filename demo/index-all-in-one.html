UGA Lit Components Demo

This page showcases all available Lit web components for UGA's eLC environment. Each component includes a live example, properties, and sample code.

For instructional designers: In production eLC pages, load the bundle with src="/shared/ugaonline/js/uga-components.js". On localhost, this page loads /dist/js/uga-components.js (run npm run build first). Design System base.css is required for shadow/radius utilities. Step-by-step setup: Setup & Usage.

Table of Contents Component

Auto-generates a navigable table of contents from h2 and h3 headings on the page. Provides smooth scrolling navigation, and auto-generates IDs for headings that don't already have one. Panel elevation uses Design System util-shadow-base and util-radius-all-sm.

Note: The TOC above this section is a live example. It scans the page's h2 and h3 headings only (h4 and lower are intentionally excluded for cleaner navigation).

Properties

No properties required - automatically scans page for headings.

<uga-toc></uga-toc>

Callout Component

Semantic callout/aside blocks with consistent brand-color pairings and an optional pseudo-label that does not create extra page headings. Corners use Design System util-radius-all-sm.

Use the standalone callout demo for focused examples and copy-paste snippets.

Properties

Property Type Description
type string One of note, important, tip, example, or warning.
label string Bold text inside the box; can be a short title or the full message (see callout demo).
body string Plain-text body in the lower section; survives eLC HTML sanitization. For richer markup, use slot content (see callout demo).
size string Optional: small, medium (default), large, or xlarge to adjust spacing and text size.
<uga-callout type="note" size="small" label="Note (Small)" body="Use note callouts for context that supports the primary instruction."></uga-callout> <uga-callout type="important" size="large" label="Important (Large)" body="Complete the identity check before opening the exam in eLC."></uga-callout> <uga-callout type="warning" size="xlarge" label="Warning (X-Large)" body="Assignments uploaded after the deadline may trigger penalties based on the syllabus policy."></uga-callout>

Image Component

Displays an image with optional caption in a styled container. Click the image to expand it in a lightbox with zoom and pan controls for viewing details. Use a relative path (e.g. image/your-image.jpg when the image is in an image/ folder next to your page) or the full path from eLC Manage Files.

Hover affordance (opt-in): Add hover-shadow to apply Design System util-shadow-hover (requires base.css). Leave it off for a static look. See Image demo.

Properties

Property Type Description
src string Image URL (required)
alt string Alternative text for accessibility (required)
caption string Caption displayed below the image
srcset string Optional. Responsive image sources
sizes string Optional. Sizes for responsive images
placeholder string Optional. Blur placeholder URL while loading
lightbox-disabled boolean Disables expand-on-click when true
hover-shadow boolean Opt-in. Applies Design System util-shadow-hover when lightbox is enabled
max-width string Max width of container (default: 450px)
border-radius number Border radius in pixels (default: 15)
border-color string Border color (default: #ba0c2f)
<uga-image src="image/your-image.jpg" alt="Description" caption="Optional caption"></uga-image> <uga-image src="image/your-image.jpg" alt="Description" caption="Optional caption" hover-shadow></uga-image>

Embeds a single Kaltura video with customizable player. Use this method when you have one video to display. Logo/watermark is hidden by default.

Properties for Single Video

Property Type Description

Quiz Component

Embed formative quizzes directly in content pages. Loads questions from a JSON file (type="local" + filename="your-quiz.json") or from an eLC CSV question-import file (type="csv" + filename="your-quiz.csv"). The JSON file must have a top-level questions array—see docs/QUIZ_JSON_FORMAT.md for the format. CSV must follow the eLC question-import layout (see quiz/quiz-sample.csv). Supports multiple question types (multiple choice, true/false, matching, short answer, multi-select, ordering), auto-grading, immediate feedback, retry attempts, timers, and submission to an eLC assignment for tracking.

Open full Quiz & Grade Sync demo — includes both JSON and CSV live examples, plus uga-quiz-grade-sync (instructor-only button to sync quiz submissions to the gradebook). Use assignment "Quiz Demo 2" with Text or File submissions, make the assignment visible to students, and set dropbox-assignment-name (or dropbox-folder-id) to test.

Properties

Property Type Description
quiz-id String Unique identifier for the quiz (used for tracking attempts)
quiz-title String Title displayed at the top of the quiz
passing-score Number Percentage required to pass (0-100, default: 70)
allow-retry Boolean Allow students to retake the quiz (default: true)
max-attempts Number Maximum number of retry attempts (default: 3)
show-feedback Boolean Show immediate feedback after answering (default: true)
randomize-questions Boolean Randomize question order (default: false)
randomize-answers Boolean Shuffle answer options within each question (default: false)
time-limit Number Time limit in minutes (0 = no limit, default: 0)
auto-submit Boolean Auto-submit when timer expires (default: false)
type String Question source: local (JSON file via filename), csv (eLC question-import CSV via filename), or inline (JSON inside the element). Default: inline.
filename String Path to the JSON or CSV file when type="local" / type="csv". Example when organized by folder: quiz/quiz-sample.json or quiz/quiz-sample.csv. Use a relative path from the HTML page or the full path from course Manage Files. See docs/QUIZ_JSON_FORMAT.md for the JSON format; CSV follows the eLC question-import layout (see the Quiz demo).
dropbox-assignment-name String Name of the eLC assignment (e.g. "Quiz Demo 2") that receives quiz submissions. The instructor must create the assignment and make it visible.
dropbox-folder-id Number Numeric assignment (dropbox) folder ID; alternative to dropbox-assignment-name. Read it from the assignment URL (db=...).

Basic Usage (JSON file)

<uga-quiz quiz-id="quiz-1" quiz-title="Formative Quiz" passing-score="70" type="local" filename="quiz/quiz-sample.json"> </uga-quiz>

Note: Create a JSON file with a questions array (see docs/QUIZ_JSON_FORMAT.md). Upload to course files (same folder as your HTML when possible). Set type="local" and filename to the filename or full path from Manage Files.

With Assignment Submission

<uga-quiz quiz-id="quiz-1" quiz-title="My Quiz" passing-score="70" type="local" filename="quiz/quiz-sample.json" dropbox-assignment-name="Quiz Demo 2"> </uga-quiz> <uga-instructor-note type="local" filename="quiz/quiz-sync-note.html"></uga-instructor-note>

Note: The instructor creates the assignment (e.g. "Quiz Demo 2") in eLC and makes it visible to students (if hidden, submissions will not pass through). Use Text or File submissions and link it to a grade item. The instructor note contains the grade sync component. When synced, the most recent grade overwrites any current grade for each student.

With Timer and Assignment Submission

<uga-quiz quiz-id="quiz-1" quiz-title="Timed Quiz" passing-score="80" time-limit="10" auto-submit="true" type="local" filename="quiz/quiz-sample.json" dropbox-assignment-name="Quiz Demo 2"> </uga-quiz> <uga-instructor-note type="local" filename="quiz/quiz-sync-note.html"></uga-instructor-note>

Note: The instructor creates the assignment (e.g. "Quiz Demo 2") in eLC and makes it visible to students (if hidden, submissions will not pass through). Use Text or File submissions and link it to a grade item. Place <uga-quiz-grade-sync dropbox-assignment-name="Quiz Demo 2"> (or dropbox-folder-id="folderId") below the quiz so instructors can run "Sync quiz grades to gradebook." When synced, the most recent grade overwrites any current grade for each student.

Course Analytics Component

Course-wide analytics aggregating data from content, assignments, and discussions. Shows module-level consumption statistics and comparisons across course modules.

Important: This component does not perform its own role check. Hide the embedding page from students with eLC release conditions before publishing.

Open full Course Analytics demo — includes detailed usage examples and property documentation.

Properties

Property Type Default Description
show-content-stats Boolean true Show content view/completion statistics
show-assignments Boolean true Show assignment submission statistics
show-discussions Boolean true Show discussion participation statistics
group-by String 'module' Grouping for analytics: module, topic, or all (currently only module is implemented)
compare-modules Boolean true Enable module comparison view with visual indicators

Basic Usage

<uga-course-analytics></uga-course-analytics>

Customized Example

<uga-course-analytics show-content-stats="true" show-assignments="true" show-discussions="false" compare-modules="true"> </uga-course-analytics>

Note: The component aggregates data from multiple eLC APIs, so loading may take several seconds for large courses. It shows overall course statistics and a module comparison table with color-coded indicators for performance relative to course averages. Always restrict the embedding page to instructors via release conditions—the component itself does not check roles.

Assignment Component

Displays assignments, discussions, quizzes, and content items from the current eLC course. Automatically fetches and displays item details including instructions, due dates, availability, rubric information, and submission links. By default, all item types are displayed. Use the types property to filter which item types to display.

Grade Export Feature: When enable-export is set, instructors can download a per-assignment CSV that lists all students, submission status, and the current gradebook value (blank if not graded yet).

Properties

Property Type Description
types String Comma-separated list of item types to include. Options: assignment, discussion, quiz, content. Default: assignment,discussion,quiz,content (all types)
enable-export Boolean Enable grade export features for instructors. When enabled, instructors see "Export Grades" (per-assignment roster CSV) and "Export All Assignments (CSV)" (course summary). Default: false

Basic Usage

<uga-assignment></uga-assignment>

Filter by Type

<!-- Show only assignments --> <uga-assignment types="assignment"></uga-assignment> <!-- Show assignments and discussions --> <uga-assignment types="assignment,discussion"></uga-assignment> <!-- Show only discussions --> <uga-assignment types="discussion"></uga-assignment>

Enable Grade Export

<!-- Enable grade export for instructors --> <uga-assignment enable-export></uga-assignment> <!-- Combine with type filtering --> <uga-assignment types="assignment" enable-export></uga-assignment>

Footer Component

Displays a branded UGA footer. Content is driven by a JSON data file. Customization happens via the JSON file in eLC. By default, loads from local course files using the filename property.

Example data file: The filename must match the file exactly. Download footer/footer-demo.json to modify and upload to your course files.

Properties

Property Type Description
filename string Name of the JSON data file (required for local files, e.g. footer/footer-demo.json). Not needed when using program or name.
program string Abbreviated template code (e.g. msw, acct, mfp, terry). Built-in logo and link; optional data-file="footer.json" for shared template JSON (see Footer demo). Same as name if only one is set; if both are set, program wins.
name string Optional alias for program (e.g. name="terry" for Terry College of Business).
imagefile string Optional. Logo filename when using program or name; if omitted, defaults to {code}.png in that template's img/ folder. For local mode, used when JSON doesn't include imageSrc.

Basic Usage (Local File)

<uga-footer filename="footer/footer-demo.json"></uga-footer>

Program Template (for instructional designers)

Use program="…" or name="…" for built-in logo and department links. Add data-file="footer.json" only when that file exists in Public Files. See Footer demo for program codes and logo paths.

<uga-footer program="msw"></uga-footer> <uga-footer name="terry"></uga-footer>

Course Calendar Component

Displays a full course calendar from JSON or CSV. Supports week separators, row types (open/due/holiday/deadline/final), assignment tags, and an optional live sync mode to align date cells with eLC assignment due dates from the current course. The scroll panel uses Design System util-shadow-base and util-radius-all-sm.

Example data files: Use course-calendar/course-calendar-demo.json or course-calendar/course-calendar-demo.csv. For CSV authoring, start with course-calendar/course-calendar-template.csv.

Properties

Property Type Description
type string Data source type: local, program, or csv
filename string Calendar file (JSON or CSV, required)
program string Program code when loading from template data
sync-from-course boolean Optional: fetches assignment due dates from the current course and updates matching date cells
sync-due-status boolean Legacy alias for sync-from-course
course-id string Optional OU override for sync mode
le-version string Optional LE API version override for sync mode

Basic Usage

<uga-course-calendar type="local" filename="course-calendar/course-calendar-demo.json"></uga-course-calendar> <uga-course-calendar type="csv" filename="course-calendar/course-calendar-demo.csv"></uga-course-calendar>

With live due-date sync (optional)

<uga-course-calendar type="local" filename="course-calendar/course-calendar-demo.json" sync-from-course> </uga-course-calendar>
