This page showcases all available Lit web components for UGA's eLC environment. Each component includes a live example, properties, and sample code.

Table of Contents Component

Auto-generates a navigable table of contents from all headings (h1-h4) on the page. Provides smooth scrolling navigation.

Note: The TOC above this section is a live example! It automatically scans all h1-h4 headings on the page.

Properties

No properties required - automatically scans page for headings.

Media Components

Single Video

Embeds a single Kaltura video with customizable player. Use this method when you have one video to display. Logo/watermark is hidden by default.

Properties for Single Video

Property Type Description
videoid string Kaltura video entry ID (required)
playerid string Kaltura player ID (default: 1574196844)
includerating boolean Add rating component below video
<uga-video videoid="1_icw0df6y" playerid="1574196844"></uga-video> <!-- With rating --> <uga-video videoid="1_icw0df6y" includerating="true"></uga-video>

Multiple Videos from JSON File

Embeds multiple Kaltura videos from a JSON data file. Use this method when you want to load multiple videos from a single JSON file. Perfect for course playlists or module video collections.

Properties for Multiple Videos

Property Type Description

Code Block Component

Displays syntax-highlighted code with copy functionality. Supports multiple languages via Prism.js. Can load from file or inline code.

function greet(name) { console.log(`Hello, ${name}!`); } greet('Student');

Properties

Property Type Description
language string Programming language for syntax highlighting
filename string Load code from external file
code string Inline code content
<uga-code language="javascript"> const x = 10; console.log(x); </uga-code> <!-- Load from file --> <uga-code language="python" filename="example.py"></uga-code>

Quiz Component

Embed formative quizzes directly in content pages. Supports multiple question types (multiple choice, true/false, matching, short answer), auto-grading, immediate feedback, retry attempts, timers, and submission to an eLC assignment for tracking. Perfect for release conditions - students can't take summative assessments until they've completed embedded formative quizzes.

Open full Quiz & Grade Sync demo — includes uga-quiz-grade-sync (instructor-only button to sync quiz submissions to the gradebook). Use assignment "Quiz Demo 2" with Text or File submissions, make the assignment visible to students, and set dropbox-folder-id to test.

Grade sync (instructor only):

Properties

Property Type Description
quiz-id String Unique identifier for the quiz (used for tracking attempts)
quiz-title String Title displayed at the top of the quiz
passing-score Number Percentage required to pass (0-100, default: 70)
allow-retry Boolean Allow students to retake the quiz (default: true)
max-attempts Number Maximum number of retry attempts (default: 3)
show-feedback Boolean Show immediate feedback after answering (default: true)
time-limit Number Time limit in minutes (0 = no limit, default: 0)
type 'csv' Load questions from eLC CSV file
filename String Path to the eLC CSV file (e.g. quiz-sample.csv)

Basic Usage (eLC CSV)

<uga-quiz quiz-id="quiz-1" quiz-title="Formative Quiz" passing-score="70" type="csv" filename="quiz-sample.csv"> </uga-quiz>

Note: Download quiz-sample.csv (Google Drive). Export questions from eLC in CSV format, save as CSV UTF-8, and upload to your course files. Update filename to match your file path.

With Timer and Assignment Submission

<uga-quiz quiz-id="quiz-1" quiz-title="Timed Quiz" passing-score="80" time-limit="10" auto-submit="true" type="csv" filename="quiz-sample.csv" dropbox-assignment-name="Quiz Demo"> </uga-quiz>

Assignment Component

Displays assignments, discussions, quizzes, and content items from the current eLC course. Automatically fetches and displays item details including instructions, due dates, availability, rubric information, and submission links. By default, all item types are displayed. Use the types property to filter which item types to display.

Grade Export Feature: When enable-export is set, instructors can download a per-assignment CSV that lists all students, submission status, and the current gradebook value (blank if not graded yet).

Properties

Property Type Description
types String Comma-separated list of item types to include. Options: assignment, discussion, quiz, content. Default: assignment,discussion,quiz,content (all types)
enable-export Boolean Enable grade export features for instructors. When enabled, instructors see "Export Grades" (per-assignment roster CSV) and "Export All Assignments (CSV)" (course summary). Default: false

Basic Usage

<uga-assignment></uga-assignment>

Filter by Type

<!-- Show only assignments --> <uga-assignment types="assignment"></uga-assignment> <!-- Show assignments and discussions --> <uga-assignment types="assignment,discussion"></uga-assignment> <!-- Show only discussions --> <uga-assignment types="discussion"></uga-assignment>

Enable Grade Export

<!-- Enable grade export for instructors --> <uga-assignment enable-export></uga-assignment> <!-- Combine with type filtering --> <uga-assignment types="assignment" enable-export></uga-assignment>

Footer Component

Displays a branded UGA footer. Content is driven by a JSON data file. Customization happens via the JSON file in eLC. By default, loads from local course files using the filename property.

Example data file: The filename must match the file exactly. Download footer-demo.json to modify and upload to your course files.

Properties

Property Type Description
filename string Name of the JSON data file (required for local files, e.g. footer-demo.json). Not needed when using program.
program string Program identifier; if not provided, defaults to local file mode.
imagefile string Name of logo image file (optional; used when JSON doesn't include imageSrc, or for program type)

Basic Usage (Local File)

<uga-footer filename="footer-demo.json"></uga-footer>

Program Template (for instructional designers)

<uga-footer program="program-name" imagefile="logo.png"></uga-footer>

Displays due dates for assignments, discussions, quizzes, and content items from the current eLC course. Automatically fetches and displays all items with due dates in a formatted table. By default, all item types are displayed. Use the types property to filter which item types to display.

Properties

Property Type Description
types String Comma-separated list of item types to include. Options: assignment, discussion, quiz, content. Default: assignment,discussion,quiz,content (all types)

Basic Usage

<uga-duedate></uga-duedate>

Filter by Type
