Component Check Sheet

Every component rendered live on one page, for checking that nothing has broken after a change to the bundle. Each entry says what a working component should look like.

Nothing here links anywhere, so the page keeps working wherever it is uploaded. Components that read the course through the Valence API stay empty outside eLC; that is expected, not a failure.

Accordion

Expect: Five collapsed rows under an Open All button. Clicking a row expands it and the plus icon changes.

Callout

Expect: Five coloured asides, each with a bold label strip and body text.

Circles

Expect: Four red circles in a row, each with a figure inside and a caption below.

Code Block

Expect: A dark block with coloured syntax, a language label and a working Copy Code button.

function greet(name) { console.log(`Hello, ${name}!`); }

Image

Expect: An image in a red frame with a caption. Clicking it opens the lightbox; Escape closes it.

Tabs

Expect: A row of tab buttons with one panel visible. Clicking another tab swaps the panel.

Video

Expect: A Kaltura player that loads a poster frame and plays on click. Only one player is on this page on purpose, since each distinct player loads its own bundle.

Slideshow

Expect: One slide with a caption, previous and next controls, and dot indicators that track the current slide.

Quiz

Expect: A quiz covering all six question types. Answering and submitting shows a score and per-question feedback. No assignment is attached here, so nothing is submitted to eLC.

Rating

Expect: A rating control with selectable options. Only fills in inside eLC.

Course Calendar

Expect: A schedule table with week separator rows and styled row types.

Footer

Expect: A branded footer with the Social Work logo and a department link.

Instructor Note

Expect: An instructor-only note. Students see nothing at all here. Only fills in inside eLC.

Instructor Card

Expect: A card with the instructor photo and name for the current course. Only fills in inside eLC.

Due Date

Expect: A table of course items that have due dates. Only fills in inside eLC.

Assignment

Expect: A detailed list of course work with dates and submission links. Only fills in inside eLC.

Course Analytics

Expect: Content, assignment and discussion figures grouped by module. Takes a few seconds on a large course. Only fills in inside eLC.

eLC and Google Sync

Expect: An admin panel showing a content preview. Running in stub mode, so the figures are placeholders and no action touches a real course.

Table of Contents and Return to Top

Expect: the contents panel near the top of this page lists every heading below, and each entry jumps to it. The Return to Top button appears at the bottom right once you scroll. Both are already on this page, so there is nothing extra to render here.
