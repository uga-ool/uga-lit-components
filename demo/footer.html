Footer Component

A branded UGA footer for the bottom of a course page. It can be driven by a JSON file in your own course files, or by a built-in program template that already carries the right logo and department link.

Add the component bundle before </body> — see Setup & Usage.

Program template

The simplest option. Set program to a code from the table below and the logo and department link are built in, with no data file to upload or maintain.

<uga-footer program="msw"></uga-footer>

name is an alias for program and behaves identically. If both are set, program wins.

Course file JSON

For a footer specific to one course, point filename at a JSON file in your course files. Use the path relative to the page when the file sits beside it, or the full path from Manage Files.

<uga-footer filename="footer/footer-demo.json"></uga-footer>

Download footer/footer-demo.json to modify and upload to your own course files.

Adding shared JSON to a program footer

A program footer shows logo and link only. Add data-file to also pull navigation, copyright and social links from the program template. Leave it off unless that file exists, otherwise the missing request shows up in broken-link reports.

<uga-footer program="msw" data-file="footer.json"></uga-footer>

While you are editing

cache-bust appends a timestamp to the JSON request so eLC serves your latest edit without a hard refresh. Useful while iterating, and worth removing once the content settles.

<uga-footer filename="footer/footer-demo.json" cache-bust></uga-footer>

Attributes

uga-footer attributes
Attribute Type Default Description
program string empty Program code, for example msw or terry. Supplies a built-in logo and department link. Takes precedence over name.
name string empty Alias for program, identical in behaviour.
filename string empty Path to a JSON file in the course files. Not needed when using program or name.
data-file string empty Used with program or name to load shared navigation, copyright and social links from the program template.
imagefile string empty Logo filename to use instead of the template default. In course-file mode, used when the JSON has no imageSrc.
cache-bust boolean false Append a timestamp to the JSON request so edits appear without a hard refresh.
