Footer Component

Displays a branded UGA footer. Content is driven by a JSON data file or a program-specific footer image stored in public files.

eLC setup: Load the component bundle with src="/shared/ugaonline/js/uga-components.js". Upload footer-demo.json to your course files. If the file is in the same folder as this page, use filename="footer-demo.json"; otherwise use the full path (e.g. /content/enforced/COURSE_ID/.../footer-demo.json). Use the abbreviated program code for program= (e.g. program="msw" for Master of Social Work). Logo paths are per-template (see list below).

Example data file: Download footer-demo.json to modify and upload to your course files.

Default footer (course file JSON)

When the file is stored locally in the course files (same folder as this page), use the filename only.

Master of Social Work footer (program template)

Properties

Property Type Description
filename string Name of the JSON data file (required for local/course files). When the file is in the same folder as the page, use the filename only, e.g. filename="footer-demo.json"; otherwise use the full path. Not needed when using program.
program string Abbreviated program code (e.g. msw, acct). When set, footer uses Program Template: data from /shared/ugaonline/templates/{program}/data/footer.json; logo path is configured per program (see list below).
imagefile string Optional. Logo image filename when using program; if omitted, defaults to {program}.png in that template's img/ folder. For local mode, used when JSON doesn't include imageSrc.

Basic usage (course file)

When the JSON file is in the same folder as the page: filename="footer-demo.json". Otherwise use the full path to the file.

<uga-footer filename="footer-demo.json"></uga-footer>

Program Template (for instructional designers)

Use the abbreviated program code with program=. Template data loads from /shared/ugaonline/templates/{program}/data/footer.json.

<uga-footer program="msw"></uga-footer>
