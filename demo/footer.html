Footer Component

Displays a branded UGA footer. Content is driven by a JSON data file or a program-specific footer image stored in public files.

eLC setup: Load the component bundle with src="/shared/ugaonline/js/uga-components.js". Upload footer/footer-demo.json (or your chosen path under Manage Files). Use filename="footer/footer-demo.json" when that folder sits next to your HTML page; otherwise use the full path from Manage Files. For a shared program template, use program="…" or name="…" (e.g. program="msw") — logo and department link are built in; no footer.json request unless you add data-file="footer.json" for nav/copyright/social from Public Files.

Example data file: Download footer/footer-demo.json to modify and upload to your course files.

Properties

Property Type Description
filename string Name of the JSON data file (required for local/course files). Example when organized by folder: filename="footer/footer-demo.json". Use the filename only when the file is next to the page, or the full path from Manage Files. Not needed when using program or name.
program string Abbreviated program code (e.g. msw, acct, terry). Uses built-in logo image and department link (see lists below). Does not fetch shared JSON unless data-file is set. Same meaning as name; if both are set, program wins.
name string Optional alias for program for instructional designers (e.g. name="terry" for Terry College of Business). Template paths and logo use this code when program is empty.
data-file string Optional, with program or name. Loads /shared/ugaonline/templates/{code}/data/{file} (e.g. data-file="footer.json") for navigation, copyright, social, and JSON overrides. Omit for logo-only footers (avoids broken-link reports when the file is missing).
imagefile string Optional. Logo image filename when using program or name; if omitted, defaults to {code}.png in that template's img/ folder. For local mode, used when JSON doesn't include imageSrc.
cache-bust boolean Optional. When set, appends a ?t=timestamp query string to the local JSON URL so eLC users see the most recent edits without a hard refresh. Useful while iterating on footer/footer-demo.json.

Basic usage (course file)

When the JSON lives under a footer/ folder next to the page: filename="footer/footer-demo.json". Otherwise use the full path from Manage Files.

<uga-footer filename="footer/footer-demo.json"></uga-footer>

Program Template (for instructional designers)

Use program="…" or name="…" for built-in logo and link. Add data-file="footer.json" only when that file exists in Public Files and you need extra footer content from JSON.

<uga-footer program="msw"></uga-footer> <!-- optional shared JSON (nav, copyright, social) --> <uga-footer program="msw" data-file="footer.json"></uga-footer> <uga-footer name="terry"></uga-footer>
