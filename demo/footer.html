Footer Component

Displays a branded UGA footer. Content is driven by a JSON data file or a program-specific footer image stored in public files.

eLC setup: Load the component bundle with src="/shared/ugaonline/js/uga-components.js". Upload footer-demo.json to your course files. If the file is in the same folder as this page, use filename="footer-demo.json"; otherwise use the full path (e.g. /content/enforced/COURSE_ID/.../footer-demo.json). For the School of Social Work footer, use program="School_of_Social_Work"; logo images live at /shared/ugaonline/templates/msw/img/.

Example data file: Download footer-demo.json to modify and upload to your course files.

Default footer (course file JSON)

When the file is stored locally in the course files (same folder as this page), use the filename only.

School of Social Work footer (program template)

Properties

Property Type Description
filename string Name of the JSON data file (required for local/course files). When the file is in the same folder as the page, use the filename only, e.g. filename="footer-demo.json"; otherwise use the full path. Not needed when using program.
program string Program name with underscores (e.g. "School_of_Social_Work"); when set, footer uses Program Template. Logo image is loaded from /shared/ugaonline/templates/msw/img/ with the same name (e.g. "School_of_Social_Work.png").
imagefile string Optional. Logo image filename when using program; if omitted, the image filename is the program name (with spaces converted to underscores) plus .png. For local mode, used when JSON doesn't include imageSrc.

Basic usage (course file)

When the JSON file is in the same folder as the page: filename="footer-demo.json". Otherwise use the full path to the file.

<uga-footer filename="footer-demo.json"></uga-footer>

Program Template (for instructional designers)

Program footers are stored in public files. Use the same program name with program= (spaces are converted to underscores for the image path).

<uga-footer program="School_of_Social_Work"></uga-footer>

Program-specific logo paths (configured in component)

  • Accounting: /shared/ugaonline/templates/acct/img/logo.png
  • School_of_Social_Work: /shared/ugaonline/templates/msw/img/SSW_logo_Horizontal_CW.png
  • Other programs: add to PROGRAM_IMAGE_PATHS in uga-footer.ts as addresses become available
