Rating Component

A short rating control for a piece of content, so learners can say whether a video or resource was useful. Responses are stored in an eLC discussion forum.

This component reads the current eLC course through the Valence API, so it only fills in when the page is viewed inside eLC. Add the component bundle before </body>.

Basic usage

Identify what is being rated. contentid is the key responses are grouped under, so keep it stable and unique; the other three describe the item for the stored record and the display.

<uga-rating contentid="module-1-intro-video" contenttype="video" contentname="Introduction Video" contentplatform="kaltura"></uga-rating>

Rating a video

For Kaltura video you do not need this tag directly. Video can render it below the player with includerating="true", which fills in the content details from the video itself.

<uga-video videoid="1_icw0df6y" name="Faculty Profile" includerating="true"></uga-video>

Attributes

uga-rating attributes
Attribute Type Default Description
contentid string empty Unique, stable identifier for the item being rated. Responses are grouped by this value, so changing it starts a new set.
contenttype string empty Kind of item, for example video or document.
contentname string empty Display name of the item.
contentplatform string empty Where the item is hosted, for example kaltura.
name string empty Optional label for the rating control itself.
