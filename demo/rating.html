Rating Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Collects user ratings for content. Integrates with eLC forums to store feedback. Useful for video ratings, resource evaluations, etc.

Properties

Property Type Description
contentid string Unique identifier for the content
contenttype string Type of content (video, document, etc.)
contentname string Display name of the content
contentplatform string Platform hosting the content
<uga-rating contentid="video-123" contenttype="video" contentname="Lecture 1" contentplatform="kaltura"> </uga-rating>
