Tabs Component

Tabbed content sections, for related material a learner can move between without leaving the page. Only the selected panel is shown.

Content comes from a JSON data file rather than from the page, so there is no markup to write beyond the tag itself. Add the component bundle before </body> — see Setup & Usage.

Basic usage

Set type="local" and point filename at a JSON file uploaded alongside the page in your course files.

<uga-tabs type="local" filename="tabs/tabs-demo.json"></uga-tabs>

Download tabs/tabs-demo.json to modify and upload to your own course files.

Data file format

The file holds a data array. Each entry needs a title for the tab button and a body, which may contain HTML.

{ "data": [ { "title": "Module Overview", "body": "<h3>Welcome to Module 1</h3><p>This module introduces the core concepts.</p>" }, { "title": "Learning Objectives", "body": "<ul><li>Identify key terminology</li><li>Apply basic principles</li></ul>" } ] }

Loading from a program folder

Set type="program" and name the program to read the same file from a shared program folder instead of the current course.

<uga-tabs type="program" program="mba" filename="tabs-demo.json"></uga-tabs>

Attributes

uga-tabs attributes
Attribute Type Default Description
type string empty Where the data file lives: local for the current course, program for a shared program folder. Nothing loads until this is set.
filename string empty Path to the JSON data file, relative to the page.
program string empty Program identifier. Required when type="program", ignored otherwise.
