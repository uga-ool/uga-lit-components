Tabs Component

Creates tabbed content sections. Ideal for organizing related content that users can switch between without leaving the page.

Example data file: Download tabs-demo.json from Google Drive and upload it to your course files.

Properties

Property Type Description
type string Data source type: 'local' or 'program'
filename string Name of the JSON data file
program string Program identifier (for program type)
<uga-tabs type="local" filename="tabs-data.json"></uga-tabs>
