Instructor Note Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and examples.

Displays notes visible only to instructors. Uses eLC role checking to hide content from students. Great for teaching notes, grading tips, etc.

Content file: The note is an HTML fragment (not JSON). Download instructor-note/instructor-note-demo.html (or copy the file in this folder), edit the HTML, and upload it to your course files. Reference it with filename="your-note.html" when it sits next to your page, or use the full path from Manage Files.

Note: Only visible to users with instructor role in eLC

Properties

Property Type Description
type string Data source type: local (course-files HTML) or program (shared template HTML)
filename string Name (or full path) of the HTML fragment that holds the note content. Use the filename when the file is next to the page; otherwise paste the full path from Manage Files.
program string Program code when loading shared template HTML (used with type="program")
<uga-instructor-note type="local" filename="instructor-note/instructor-note-demo.html"></uga-instructor-note>

The HTML in the file is rendered inside a styled callout. See instructor-note/instructor-note-demo.html for sample markup (in eLC, upload under instructor-note/ and use filename="instructor-note/instructor-note-demo.html").
