Instructor Note Component

A note that only instructors can see, for teaching notes, grading reminders, or facilitation tips left inside the course content.

This component reads the current eLC course through the Valence API, so it only fills in when the page is viewed inside eLC. Students and demo students never see the note. Add the component bundle before </body> — see Setup & Usage.

Basic usage

Set type="local" and point filename at the note. Note that the file is an HTML fragment, not JSON, so you write the note as ordinary markup.

<uga-instructor-note type="local" filename="instructor-note/instructor-note-demo.html"></uga-instructor-note>

Download instructor-note/instructor-note-demo.html to modify and upload to your own course files. Use the filename alone when the file sits next to the page, or the full path from Manage Files.

A short note inline

For a single sentence, skip the file and use the text attribute. Plain text only, which also means it survives eLC HTML sanitization.

<uga-instructor-note text="Remind students that the rubric changed this term."></uga-instructor-note>

Loading from a program folder

Set type="program" and name the program to read a shared note from a program template instead of the current course.

<uga-instructor-note type="program" program="mba" filename="instructor-note.html"></uga-instructor-note>

Attributes

uga-instructor-note attributes
Attribute Type Default Description
type string empty Where the note file lives: local for the current course, program for a shared program folder.
filename string empty Path to the HTML fragment holding the note, relative to the page, or the full path from Manage Files.
program string empty Program identifier. Required when type="program", ignored otherwise.
text string empty A plain-text note written directly on the tag, instead of loading a file.
