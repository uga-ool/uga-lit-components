Sync quiz grades to gradebook (instructor only):

This sync uses dropbox-assignment-name="Quiz Demo 2" so the folder ID is looked up by assignment name. You can instead set dropbox-folder-id to the assignment's folder ID (from the assignment URL db=...). The assignment should allow Text or File submissions and be linked to a grade item. When synced, the most recent grade overwrites any current grade for each student in that grade item.
