Return to Top Component

A button that appears once the learner has scrolled down and returns them to the top of the page. Useful on long content pages where the navigation sits at the top.

The button at the bottom right of this page is this component. Add the component bundle before </body>.

Basic usage

Place the tag once, just before the closing </body> tag. It positions itself and stays hidden until there is something to scroll back to, so it needs no configuration.

<uga-return-to-top></uga-return-to-top>

Attributes

None. The component takes no attributes and has no options to set.
