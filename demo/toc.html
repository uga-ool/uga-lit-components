Table of Contents Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Local preview: This page loads /dist/js/uga-components.js on localhost (run npm run build first). Requires Design System base.css for shadow/radius utilities on the TOC panel.

Auto-generates a navigable table of contents from h2 and h3 headings on the page. Provides smooth scrolling navigation. Panel elevation uses Design System util-shadow-base and util-radius-all-sm.

Note: The TOC below is a live example! It automatically scans all h2 and h3 headings on the page.

No properties required - automatically scans page for h2 and h3 headings.
