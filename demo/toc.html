Table of Contents Component

Builds a navigable table of contents from the headings already on the page, so there is nothing to keep in sync by hand. The panel near the top of this page is this component.

Add the component bundle before </body> — see Setup & Usage.

Basic usage

Drop the tag wherever the panel should appear, usually just below the page intro. It collects h2 and h3 by default, gives any heading without an id a generated one, and links to each. Only one belongs on a page, so the example below is not rendered a second time here.

<uga-toc></uga-toc>

Choosing heading levels

Pass a comma-separated list to headings to change which levels are collected. Bare numbers work too, so 2,3 means the same as h2,h3. Levels below what you list are skipped, so an h4 only appears if you ask for it.

<uga-toc headings="h2"></uga-toc>
<uga-toc headings="h2,h3,h4"></uga-toc>
<uga-toc headings="2,3"></uga-toc>

Attributes

uga-toc attributes
Attribute Type Default Description
headings string h2,h3 Comma-separated heading tags to collect, for example h2,h3,h4. Accepts bare numbers. Invalid entries are ignored, and if nothing valid remains it falls back to h2,h3.
