Table of Contents Component

Auto-generates a navigable table of contents from h1 through h6 headings on the page. Provides smooth scrolling navigation with proper nesting.

Note: The TOC below is a live example! It automatically scans all headings (h1-h6) with id attributes on the page.

Properties

No properties required - automatically scans page for h1 through h6 headings that have id attributes.

Important: Headings must have an id attribute to appear in the table of contents. The component will skip its own "Contents" heading to prevent self-reference.

Behavior: The first heading level found becomes the root level. All subsequent headings nest appropriately based on their level relative to the root.
