Table of Contents Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Local preview: This page loads /dist/js/uga-components.js on localhost (run npm run build first). Requires Design System base.css for shadow/radius utilities on the TOC panel.

Auto-generates a navigable table of contents from page headings. Defaults to h2 and h3. Use the optional headings attribute to choose which levels to include (comma-separated, e.g. h2,h3,h4). Provides smooth scrolling navigation. Panel elevation uses Design System util-shadow-base and util-radius-all-sm.

Note: The TOC below is a live example using the default (h2, h3). The sample h4 below is omitted unless you set headings="h2,h3,h4".

Properties

  • headings (optional) — Comma-separated heading tags to include. Default: h2,h3. Examples: h2, h2,h3,h4, 2,3.
<uga-toc></uga-toc> <!-- Include h4 as well --> <uga-toc headings="h2,h3,h4"></uga-toc>
