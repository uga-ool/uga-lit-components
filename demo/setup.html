Setup & Usage

Complete guide to setting up and using UGA Lit Components in eLC.

This page covers installation, configuration, and data file creation for all components.

How to Use These Components in eLC

1. Add to Your Page

Create a new HTML page in eLC and add your components:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Page</title> <link rel="stylesheet" href="https://design.online.uga.edu/css/base.css"> </head> <body> <h1>My Course Content</h1> <!-- Your components --> <uga-accordion type="local" filename="my-accordion.json"></uga-accordion> <uga-video videoid="1_icw0df6y"></uga-video> <!-- Load bundle at end of page --> <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> </body> </html>

If you maintain a separate testing location, swap the script path to /shared/ugaonline/dev/js/uga-components.js.

2. Create Data Files (for components that need them)

Many components load data from JSON files; the Quiz component uses CSV. Upload files to eLC course files and reference them by the full file path (or relative path if in the same directory as your HTML).

How to find the file path in eLC:

  1. Go to Content → Manage Files (or Course Admin → Manage Files)
  2. Upload your JSON file
  3. Right-click the file and select View File Path or Copy Path
  4. The path will look like: /content/enforced/12345-123456/your-file.json
  5. Use this full path in your component's filename attribute

Note: JSON files don't display visually in eLC - they're loaded by components in the background for configuration purposes.

Example: accordion-data.json

{ "title": "Course FAQ", "data": [ { "title": "How do I submit assignments?", "body": "<p>Go to the Assignments page and click Submit.</p>" }, { "title": "When are office hours?", "body": "<p>Tuesday and Thursday, 2-4 PM EST.</p>" } ] }

Example: tabs-data.json

{ "data": [ { "title": "Overview", "body": "<p>This module covers...</p>" }, { "title": "Learning Objectives", "body": "<ul><li>Objective 1</li></ul>" } ] }

Example: circles-data.json

{ "data": [ { "figure": "85%", "caption": "Pass Rate" }, { "figure": "150", "caption": "Students Enrolled" } ] }

Example: slideshow-data.json

{ "data": [ { "image": "/shared/PublicFiles/images/slide1.jpg", "caption": "Introduction to the course" }, { "image": "/shared/PublicFiles/images/slide2.jpg", "caption": "Key concepts overview" } ] }

Example: footer-demo.json

{ "data": { "link": "https://online.uga.edu", "alt": "University of Georgia Online Learning Logo", "imageSrc": "https://design.online.uga.edu/images/uga-logo.png" } }

Use filename="footer-demo.json" for local files. The program property loads from shared program templates when set.

Example: instructor-note-data.json

{ "content": "<p>This is a note only visible to instructors.</p><ul><li>Grading tip 1</li><li>Grading tip 2</li></ul>" }

Example: videos-data.json (for multiple videos)

{ "data": [ { "videoid": "1_abc123de", "title": "Introduction Video" }, { "videoid": "1_xyz789fg", "title": "Lecture 1" } ] }

Quiz component: CSV (not JSON)

The uga-quiz component loads questions from an eLC-format CSV file. Use type="csv" and filename pointing to your CSV. Download quiz-sample.csv (Google Drive) for a sample with all six question types. Save as CSV UTF-8; upload to eLC and set the path in filename. See the Quiz demo for full usage.

3. Component-Specific Setup

eLC API Components

These components require eLC API access and will only work in eLC:

  • uga-assignment - Displays assignments, discussions, quizzes, and content with due dates from the current eLC course. By default, all item types are displayed. Use the types property to filter (e.g., types="assignment,discussion"). Supports grade export when enable-export is set.
  • uga-duedate - Displays due dates for assignments, discussions, quizzes, and content in a formatted table. By default, all item types are displayed. Use the types property to filter (e.g., types="assignment").
  • uga-quiz - Embed formative quizzes; loads questions from a CSV file (type="csv", filename). Can submit results to an eLC assignment. See Quiz demo and quiz-sample.csv.
  • uga-instructor-note - Visible only to instructors (uses eLC role checking)
  • uga-rating - Stores ratings in eLC forums

Assignment & Due Date Components - Type Filtering

Both uga-assignment and uga-duedate support filtering by item type:

<!-- Show all types (default) --> <uga-assignment></uga-assignment> <!-- Show only assignments --> <uga-assignment types="assignment"></uga-assignment> <!-- Show assignments and discussions --> <uga-assignment types="assignment,discussion"></uga-assignment> <!-- Show only discussions --> <uga-duedate types="discussion"></uga-duedate>

Available types: assignment, discussion, quiz, content

Kaltura Video Component

For uga-video, you'll need:

  • videoid - The Kaltura entry ID (found in Kaltura MediaSpace)
  • playerid (optional) - Custom player ID (default: 1574196844)
  • uiconfid (optional) - UI configuration ID for custom player appearance

4. Troubleshooting

Components Not Showing

  • Verify the script tag is at the end of your HTML (before closing </body>)
  • Check browser console for errors (F12)
  • Ensure the bundle path is correct: /shared/ugaonline/js/uga-components.js

Data Not Loading

  • Verify JSON file paths are correct relative to Public Files
  • Check JSON syntax is valid (use a JSON validator)
  • For uga-quiz: use a CSV file (not JSON), save as CSV UTF-8, and set type="csv" and filename to the file path
  • Ensure files are uploaded to the correct location in eLC

Accordion Icons Not Showing

  • Add class="js" to your <html> tag: <html lang="en" class="js">
  • This enables the UGA CSS pseudo-element styles for accordion icons

eLC API Errors

  • These components only work inside eLC
  • Verify you're testing in the eLC environment, not locally
  • Check browser console for specific API error messages
