Setup and Usage

How to put UGA Lit Components on an eLC page: loading the bundle, uploading data files, and finding the paths eLC expects.

Every component page links here, so this is the one page to read first.

Adding components to a page

Load the design system stylesheet in the <head> and the component bundle just before </body>. The components are custom elements, so once the bundle loads, any tag on the page starts working.

<!DOCTYPE html> <html lang="en" class="no-js"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Page</title> <link rel="stylesheet" href="https://design.online.uga.edu/css/base.css" /> </head> <body> <a class="cmp-skip-to-content" href="#main-content">Skip to main content</a> <main id="main-content"> <h1>My Course Content</h1> <uga-accordion type="local" filename="my-accordion.json"></uga-accordion> <uga-video videoid="1_icw0df6y"></uga-video> <uga-image src="image/photo.jpg" alt="Description of the image" caption="Optional caption"></uga-image> </main> <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> <script src="https://design.online.uga.edu/js/scripts.js"></script> </body> </html>

Include base.css even if you use no design system classes of your own. Several components rely on its utilities for shadows and rounded corners, and without it they render unstyled.

Uploading data files

Components such as Accordion, Tabs, Circles, Slideshow and Course Calendar read their content from a file rather than from the page. Upload the file to your course files, then reference it from the tag.

A path relative to the page works when the file sits beside it, which is why the examples across these pages use forms like accordion/accordion-demo.json. Otherwise use the full path from Manage Files.

Finding a file path in eLC

Go to Content then Manage Files, or Course Admin then Manage Files. Upload the file, right-click it and choose View File Path or Copy Path. The result looks like /content/enforced/12345-123456/your-file.json, and that whole string goes in the filename attribute.

A JSON file uploaded this way does not appear as course content to students. It sits in the file area and is read by the component in the background.

Data file examples

Each component page documents its own format, and the examples below are a quick reference. Downloadable copies are linked from the individual pages.

Accordion and Tabs share a shape: a data array of entries with a title and an HTML body.

{ "title": "Course FAQ", "data": [ { "title": "How do I submit assignments?", "body": "<p>Go to Assignments and choose Submit.</p>" }, { "title": "When are office hours?", "body": "<p>Tuesday and Thursday, 2 to 4 PM Eastern.</p>" } ] }

Circles takes a figure and a caption per entry.

{ "data": [ { "figure": "85%", "caption": "Pass Rate" }, { "figure": "150", "caption": "Students Enrolled" } ] }

Slideshow needs src and alt on every slide, with title and description forming the caption.

{ "title": "Course Walkthrough", "id": "course-walkthrough", "data": [ { "src": "image/step-1.jpg", "alt": "The course home page with announcements at the top", "title": "Step 1: Course Home", "description": "Start at the course home page." } ] }

Course Calendar groups rows into weeks. The full format is in docs/COURSE_CALENDAR_FORMAT.md, and a CSV alternative is described on the component page.

{ "data": { "weeks": [ { "label": "Week 1 - May 12-18 - Classes Begin", "rows": [ { "type": "open", "date": "May 12", "day": "Tuesday", "moduleTitle": "Modules 00, 01 and 02 Open", "event": "Classes Begin" } ] } ] } }

Instructor Note is the exception: its file is an HTML fragment, not JSON, so you write the note as ordinary markup.

Troubleshooting

A component renders as an empty space. The bundle did not load. Check that the <script type="module"> tag is present and that the path resolves in your course.

The component appears but has no content. The data file was not found. The path is the usual cause; try the full Manage Files path rather than a relative one.

Corners and shadows look wrong. base.css is missing from the page.

An attribute seems to be ignored. Check the spelling against the attributes table on that component’s page. A few attributes are all lowercase rather than hyphenated, notably quizid, quiztitle and passingscore on Quiz, and a misspelled attribute fails silently rather than reporting an error.
