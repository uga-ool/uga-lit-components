Assignment Component

A detailed list of course work: instructions, due dates, availability, rubric information and submission links for assignments, discussions, quizzes and content items.

This component reads the current eLC course through the Valence API, so it only fills in when the page is viewed inside eLC. It is the fuller counterpart to Due Date, which shows dates alone. Add the component bundle before </body> — see Setup & Usage.

Basic usage

With no attributes it lists every item type. The course is detected from the page URL, so there is nothing to configure.

<uga-assignment></uga-assignment>

Filtering by type

Pass types a comma-separated list to narrow what appears, the same options as Due Date.

<uga-assignment types="assignment"></uga-assignment>
<uga-assignment types="quiz,discussion"></uga-assignment>

Grade export

Add enable-export and instructors gain two CSV downloads: per-assignment, listing every student with their submission status and current gradebook value, and a course-level summary of all assignments. Students never see the buttons, so the attribute is safe to leave on a page they also read.

<uga-assignment enable-export></uga-assignment>

Exported files carry student names and grades, so treat them as FERPA-protected records once downloaded.

Attributes

uga-assignment attributes
Attribute Type Default Description
types string assignment,discussion,quiz,content Comma-separated list of item types to include. Any of assignment, discussion, quiz, content.
enable-export boolean false Show grade export buttons to instructors. Has no effect for students.
