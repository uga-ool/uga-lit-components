Assignment Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Displays assignments, discussions, quizzes, and content items from the current eLC course. Automatically fetches and displays item details including instructions, due dates, availability, rubric information, and submission links. By default, all item types are displayed. Use the types property to filter which item types to display.

Grade Export Feature: When enable-export is set, instructors can download a CSV for an assignment that lists all students, whether they submitted, and their current gradebook value (blank if not graded yet).

With Grade Export Enabled (Instructor View)

Note: Grade export features are only visible to instructors. Students will see the standard assignment list.

When enable-export is set, instructors see "Export Grades" buttons for each assignment. Clicking it downloads a per-assignment CSV (all students + submission status + gradebook value). The "Export All Assignments (CSV)" button exports a course-level summary of assignments and gradebook metadata.

Properties

Property Type Description
types String Comma-separated list of item types to include. Options: assignment, discussion, quiz, content. Default: assignment,discussion,quiz,content (all types)
enable-export Boolean Enable grade export features for instructors. When enabled, instructors see "Export Grades" (per-assignment roster CSV) and "Export All Assignments (CSV)" (course summary). Default: false

Basic Usage

<uga-assignment></uga-assignment>

Filter by Type

<!-- Show only assignments --> <uga-assignment types="assignment"></uga-assignment> <!-- Show assignments and discussions --> <uga-assignment types="assignment,discussion"></uga-assignment> <!-- Show only discussions --> <uga-assignment types="discussion"></uga-assignment>

Enable Grade Export

<!-- Enable grade export for instructors --> <uga-assignment enable-export></uga-assignment> <!-- Combine with type filtering --> <uga-assignment types="assignment" enable-export></uga-assignment>

How Grade Export Works

Grade Export Feature:

  1. Instructor enables export - Set enable-export attribute on the component. This makes export buttons visible to instructors only.
  2. Export individual assignment grades - Click "Export Grades" button next to any assignment. This:
    • Finds the grade object in the gradebook that matches the assignment name
    • Loads the classlist to include every student
    • Loads submissions to mark who submitted
    • Loads gradebook values (if any) and leaves blanks for ungraded work
    • Downloads a per-assignment CSV
  3. Export all assignments summary - Click "Export All Assignments (CSV)" button at the top. This:
    • Creates a CSV file with all assignments
    • Includes assignment name, due date, type, grade object ID, max points, and student count
    • Downloads the CSV file automatically

Important Notes:

  • Grade objects must exist - The assignment must have a corresponding grade object in the eLC gradebook. The component matches assignments to grade objects by name.
  • Export reads existing grades - The export feature reads grades that already exist in the gradebook. It does not create new grades or autograde submissions.
  • Instructor-only feature - Students will not see the export buttons, only the standard assignment list.
