Slideshow Component

An image slideshow with previous and next controls and dot indicators, for visual walkthroughs, step-by-step instructions, or a gallery.

Slides come from a JSON data file rather than from the page. Add the component bundle before </body> — see Setup & Usage.

Basic usage

Point filename at a JSON file uploaded alongside the page. Unlike most data-driven components here, the slideshow has no type attribute; the filename is the whole configuration.

<uga-slideshow filename="slideshow/slideshow-demo.json" imageheight="400"></uga-slideshow>

Download slideshow/slideshow-demo.json to modify and upload to your own course files.

Data file format

The file carries a title, a description and an id for the slideshow as a whole, then a data array of slides. Every slide needs src and alt; title and description appear as the caption.

{ "title": "Course Walkthrough", "description": "Step-by-step guide to navigating your course", "id": "course-walkthrough", "data": [ { "src": "image/step-1.jpg", "alt": "The course home page with announcements at the top", "title": "Step 1: Course Home", "description": "Start at the course home page for announcements and quick links." } ] }

Write alt for every slide. It is the only description a screen reader gets, and the caption text does not substitute for it.

Image height

imageheight sets the slide height in pixels and defaults to 500. Pick one height that suits the whole set, since every slide uses it.

<uga-slideshow filename="slideshow/slideshow-demo.json" imageheight="400"></uga-slideshow>

Attributes

uga-slideshow attributes
Attribute Type Default Description
filename string empty Path to the JSON data file, relative to the page.
imageheight string 500 Slide height in pixels, applied to every slide.
initialloadheight string 700 Height reserved before the data arrives, which keeps the page from jumping as slides load.
