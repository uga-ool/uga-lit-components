Slideshow Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Local preview: This page loads /dist/js/uga-components.js on localhost (run npm run build first). Requires Design System base.css for control radius utilities.

Creates an image slideshow with navigation controls. Perfect for visual content, step-by-step instructions, or image galleries. Dot indicators and prev/next controls use Design System radius utilities (util-radius-all-circle, util-radius-left-sm / util-radius-right-sm).

Example data file: Download slideshow/slideshow-demo.json to modify and upload it to your course files.

Properties

Property Type Description
filename string Name of the JSON data file
imageheight string Height of images in pixels (default: 500)
<uga-slideshow filename="slideshow/slideshow-demo.json" imageheight="400"></uga-slideshow>
