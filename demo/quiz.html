Quiz Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Embed formative quizzes directly in content pages. Supports multiple question types (multiple choice, multi-select, ordering, true/false, matching, short answer), auto-grading, immediate feedback, retry attempts, timers, and submission to an eLC assignment for tracking.

Use Case: Students can't take summative assessments until they've completed embedded formative quizzes (release conditions).

Demo: All Question Types and Features

This demo uses quiz-sample.json, which includes all six question types: Multiple Choice, True/False, Short Answer, Matching, Multi-Select, and Ordering. The quiz below has all features enabled: timer (10 min with auto-submit), question randomization, retries, immediate feedback, and submission to the eLC assignment Quiz Demo 2.

How to use a JSON file: (1) Create a JSON file with a questions array (see docs/QUIZ_JSON_FORMAT.md for the format). (2) Upload the file to course files (same folder as your HTML page when possible). (3) Set type="local" and filename="your-file.json" on the quiz. Use a filename only (e.g. quiz-sample.json) when the JSON is in the same folder as the page, or the full path from Manage Files (e.g. /content/enforced/…/quiz-sample.json). Shared institutional paths like /shared/PublicFiles/… are optional if your unit hosts files there.

Basic (CSV, no timer):

<uga-quiz 
  quiz-id="demo-quiz"
  quiz-title="My Quiz"
  passing-score="70"
  type="local"
  filename="quiz-sample.json">
</uga-quiz>

With assignment submission:

<uga-quiz 
  quiz-id="demo-quiz"
  quiz-title="My Quiz"
  passing-score="70"
  type="local"
  filename="quiz-sample.json"
          dropbox-assignment-name="Quiz Demo 2">
</uga-quiz>
<uga-quiz-grade-sync dropbox-assignment-name="Quiz Demo 2"></uga-quiz-grade-sync>
<!-- or use dropbox-folder-id="12345" with the assignment URL db= value -->

All features (timer, auto-submit, randomize):

<uga-quiz 
  quiz-id="demo-quiz"
  quiz-title="Quiz: All Types & Features"
  passing-score="70"
  allow-retry="true"
  max-attempts="99"
  show-feedback="true"
  randomize-questions="true"
  time-limit="10"
  auto-submit="true"
  type="local"
  filename="quiz-sample.json"
          dropbox-assignment-name="Quiz Demo 2">
</uga-quiz>

Note: The instructor creates the assignment (e.g. "Quiz Demo 2") in eLC and makes it visible to students (if hidden, submissions will not pass through). Use Text or File submissions and link it to a grade item. Place <uga-quiz-grade-sync dropbox-assignment-name="Quiz Demo 2"> (or dropbox-folder-id="folderId") below the quiz so instructors can run "Sync quiz grades to gradebook." When synced, the most recent grade overwrites any current grade for each student.

JSON Question Format

The quiz component loads questions from a JSON file. The file must have a top-level questions array. Each question has id, type, question, points, correctAnswer, and optionally options, explanation, caseSensitive. See docs/QUIZ_JSON_FORMAT.md for the full format and examples.

Question types and correctAnswer format:

  • multiple-choice: options array, correctAnswer = index (0-based)
  • true-false: options ["True","False"], correctAnswer = 0 or 1
  • short-answer: correctAnswer string, optional caseSensitive
  • matching: options = match list, correctAnswer = object mapping choice text to match text
  • multi-select: options array, correctAnswer = array of correct indices
  • ordering: options array in correct order, correctAnswer = [0,1,2,...]

Steps to use a JSON file:

  1. Create a JSON file with a questions array (see quiz-sample.json, quiz10.json, or quiz20.json in the demo folder)
  2. Upload the JSON file to the same folder as your HTML page, or to eLC Public Files
  3. Add type="local" and filename="your-file.json" to the quiz component (filename only if same folder as the page, or full course-files path from Manage Files)

Properties

Property Type Default Description
quiz-id string '' Unique identifier for the quiz (used for tracking attempts)
quiz-title string '' Title displayed at the top of the quiz
type 'local' 'local' Load questions from JSON file
filename string '' Path to the JSON file. Use a filename only (e.g. quiz-sample.json) if the file is in the same folder as the HTML page, or the full path from course Manage Files. Required when type="local". See docs/QUIZ_JSON_FORMAT.md for JSON format.
passing-score number 70 Percentage required to pass (0-100)
allow-retry boolean true Allow students to retake the quiz
max-attempts number 3 Maximum number of retry attempts
show-feedback boolean true Show immediate feedback after answering
randomize-questions boolean false Randomize question order
time-limit number 0 Time limit in minutes (0 = no limit)
auto-submit boolean false Automatically submit when time expires
dropbox-folder-id number 0 eLC assignment (folder) ID. If set, each quiz completion is submitted to that assignment for audits and tracking. Use an assignment with All submissions are kept. See docs/D2L_QUIZ_DROPBOX.md.
dropbox-assignment-name string '' Name of the eLC assignment (e.g. "Quiz Demo 2"). The instructor creates this assignment in eLC (Assignments) and makes it visible; if hidden, the component cannot find it and submissions fail. Use the exact assignment title here. See docs/D2L_QUIZ_DROPBOX.md.

Question Types (in CSV)

  • multiple-choice: options array, correctAnswer is index (0-based)
  • multi-select: options array, correctAnswer is array of indices, e.g. [0, 2]
  • ordering: options array (items in correct order), correctAnswer is [0, 1, 2, ...]. User arranges with up/down.
  • true-false: correctAnswer is boolean (true/false)
  • short-answer: correctAnswer is string, optional caseSensitive
  • fill-in-blank: Same as short-answer
  • matching: options array, correctAnswer is object like {"A": "Option 1", "B": "Option 2"}

Features

  • ✅ Multiple question types (MC, Multi-Select, Ordering, T/F, Matching, Short Answer)
  • ✅ Auto-grading with immediate feedback

Automating submission to the gradebook (instructor)

Instructors can send quiz results from the assignment into the eLC gradebook in one step:

  1. In eLC: Create the assignment (e.g. Quiz Demo 2), make it visible, set Text or File and All submissions are kept. In the assignment’s Grade (or Evaluation & Feedback) settings, link the assignment to a grade item in the gradebook (e.g. create or select a grade item so the assignment is tied to that column).
  2. Get the assignment folder ID: In eLC, open the assignment; the URL contains db= followed by a number (e.g. db=12345). That number is the dropbox folder ID.
  3. In your content: Place <uga-quiz-grade-sync dropbox-assignment-name="Quiz Demo 2"></uga-quiz-grade-sync> below the quiz (use the same assignment name as the quiz’s dropbox-assignment-name). Alternatively use dropbox-folder-id="12345" with the folder ID from the assignment URL (db=...). This component is visible only to instructors.
  4. When you want to update grades: Open the page as an instructor and click Sync quiz grades to gradebook. The component reads all quiz submissions from that assignment and writes each student’s score into the linked grade item. The most recent grade overwrites any current grade for each student. Run it whenever new submissions have come in.

There is no separate eLC setting to “automate” this—the one-click sync button is the automation. Students never write to the gradebook; only instructors trigger the sync.

Setup Requirements

  1. Assignment: Instructor creates an assignment in eLC (Assignments) with the same name as dropbox-assignment-name (e.g. "Quiz Demo 2"). Make the assignment visible to students (if hidden, submissions will not pass through). Set All submissions are kept. See docs/D2L_QUIZ_DROPBOX.md.
  2. Questions: Use the provided quiz-sample.json (all six question types) or create your own JSON file with a questions array. See the sample file for the required structure.
  3. Upload Files: Place the CSV in your course content area (same directory as your HTML page, or set filename to the path).
  4. Course Context: Component must be used within an eLC course page (for API access and assignment submission).
