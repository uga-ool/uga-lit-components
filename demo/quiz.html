Quiz Component

A formative quiz embedded directly in a content page. It supports multiple choice, multi-select, true/false, ordering, matching and short answer, with auto-grading, immediate feedback, retries and an optional timer.

Results can be submitted to an eLC assignment, which makes it possible to gate a summative assessment behind release conditions. Add the component bundle before </body>.

A note on attribute spelling

Most attributes here are hyphenated, such as allow-retry and time-limit. Three are not: quizid, quiztitle and passingscore are written all lowercase, with no hyphens, because of how the component declares them.

The hyphenated spellings quiz-id, quiz-title and passing-score are silently ignored. They do not raise an error; the quiz simply keeps its default title and passing score. If you have course HTML using those, correct it to the lowercase forms.

Questions from a JSON file

Set type="local" and point filename at a JSON file holding a questions array. The format is documented in docs/QUIZ_JSON_FORMAT.md.

<uga-quiz type="local" filename="quiz/quiz-sample.json" quizid="module-1-check" quiztitle="Module 1 Knowledge Check" passingscore="70"></uga-quiz>

Question file format

Each question needs an id, a type, the question text and points. Multiple choice uses options with a zero-based correctAnswer. explanation is shown as feedback.

{ "questions": [ { "id": "q1", "type": "multiple-choice", "question": "What is the primary purpose of formative assessment?", "points": 20, "options": [ "To assign final grades", "To provide feedback during learning", "To rank students" ], "correctAnswer": 1, "explanation": "Formative assessment guides learning while it is still in progress." } ] }

Questions from an eLC CSV

Set type="csv" to load an eLC question-library CSV export instead. Only the eLC layout parses; a general spreadsheet will not. Lines beginning // are treated as comments. Both sources produce the same quiz, so use whichever your team already authors.

<uga-quiz type="csv" filename="quiz/quiz-sample.csv" quizid="module-1-csv" quiztitle="Module 1 Knowledge Check"></uga-quiz>

quiz/quiz-sample.csv in this folder covers all six question types and works as a template. The repository also has npm run quiz:csv-to-json for converting a CSV to the JSON format.

Retries and feedback

Retries are on by default with three attempts, and feedback is shown immediately. Turn feedback off when the same questions are reused as a graded check.

<uga-quiz type="local" filename="quiz/quiz-sample.json" allow-retry="true" max-attempts="99"></uga-quiz>
<uga-quiz type="local" filename="quiz/quiz-sample.json" allow-retry="false" show-feedback="false"></uga-quiz>

Randomizing

randomize-questions shuffles the question order and randomize-answers shuffles options within each question. Both are off by default. Avoid answer randomization on questions whose options read "all of the above".

<uga-quiz type="local" filename="quiz/quiz-sample.json" randomize-questions="true" randomize-answers="true"></uga-quiz>

Timing

time-limit is in minutes and 0 means no limit. Add auto-submit to submit automatically when the time runs out, rather than leaving the attempt open.

<uga-quiz type="local" filename="quiz/quiz-sample.json" time-limit="10" auto-submit="true"></uga-quiz>

Submitting to an eLC assignment

Name an existing assignment with dropbox-assignment-name and the result is submitted there as a file, so completion can drive a release condition. The assignment must already exist in eLC, allow Text or File submissions, and be linked to a grade item. dropbox-folder-id does the same by ID, taken from the db= value in the assignment URL.

<uga-quiz type="local" filename="quiz/quiz-sample.json" dropbox-assignment-name="Quiz Demo 2"></uga-quiz>
<uga-quiz type="local" filename="quiz/quiz-sample.json" dropbox-folder-id="12345"></uga-quiz>

Syncing grades

<uga-quiz-grade-sync> is a separate, instructor-only control that pushes submitted quiz results into the gradebook. Point it at the same assignment as the quiz. When it runs, the most recent grade overwrites any existing grade for that student in that grade item, so it is not safe to run after manual adjustments.

<uga-quiz-grade-sync dropbox-assignment-name="Quiz Demo 2"></uga-quiz-grade-sync>

Place it inside an Instructor Note so students never see the control. quiz/quiz-sync-note.html in this folder is a ready-made fragment that does exactly that.

Attributes

uga-quiz attributes
Attribute Type Default Description
type string inline Question source: local for a JSON file, csv for an eLC CSV export, inline for questions passed directly.
filename string empty Path to the question file, relative to the page. Used with type="local" or type="csv".
questions string empty Questions as a JSON string, for type="inline".
quizid string empty Stable identifier for this quiz. All lowercase, not quiz-id. Generated automatically if omitted, which makes stored feedback less reliable.
quiztitle string empty Title shown above the quiz. All lowercase, not quiz-title.
passingscore number 70 Percentage needed to pass. All lowercase, not passing-score.
allow-retry boolean true Let learners reattempt the quiz.
max-attempts number 3 Maximum number of attempts when retries are allowed.
show-feedback boolean true Show the answer explanation immediately after each question.
randomize-questions boolean false Shuffle the order of questions.
randomize-answers boolean false Shuffle options within each question.
time-limit number 0 Time limit in minutes. 0 means no limit.
auto-submit boolean false Submit automatically when the time limit is reached.
dropbox-assignment-name string empty Name of an existing eLC assignment to submit the result to.
dropbox-folder-id number 0 Assignment folder ID to submit to, from the db= value in the assignment URL.

Grade sync attributes

For the separate <uga-quiz-grade-sync> element.

uga-quiz-grade-sync attributes
Attribute Type Default Description
dropbox-assignment-name string empty Name of the assignment holding the submitted quiz results.
dropbox-folder-id number 0 Assignment folder ID, as an alternative to the name.
ou string empty Course OU, when it should not be taken from the page URL.
