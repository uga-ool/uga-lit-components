Quiz Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON / CSV examples.

Embed formative quizzes directly in content pages. Supports multiple question types (multiple choice, multi-select, ordering, true/false, matching, short answer), auto-grading, immediate feedback, retry attempts, timers, and submission to an eLC assignment for tracking.

Question source: load from a JSON file with type="local" (component format) or from an eLC CSV export with type="csv". Pick whichever your team already authors—both render the same quiz UI.

Use Case: Students can't take summative assessments until they've completed embedded formative quizzes (release conditions).

Demo: All Question Types and Features (JSON)

This demo uses quiz/quiz-sample.json, which includes all six question types: Multiple Choice, True/False, Short Answer, Matching, Multi-Select, and Ordering. The quiz below has all features enabled: timer (10 min with auto-submit), question randomization, retries, immediate feedback, and submission to the eLC assignment Quiz Demo 2.

How to use a JSON file: (1) Create a JSON file with a questions array (see docs/QUIZ_JSON_FORMAT.md for the format). (2) Upload the file to course files (e.g. a quiz/ folder next to your HTML page). (3) Set type="local" and filename on the quiz—this demo uses quiz/quiz-sample.json. Use a path relative to the page, or the full path from Manage Files. Shared institutional paths like /shared/PublicFiles/… are optional if your unit hosts files there.

Demo: Same Quiz from eLC CSV

This demo uses quiz/quiz-sample.csv in the eLC question import (CSV) format. It loads the same six question types as the JSON demo above. Set type="csv" and point filename at the CSV file.

How to use a CSV file: (1) Export questions from eLC's question library, or hand-author a CSV in the eLC format (see quiz/quiz-sample.csv in this repo for a template covering all six types). (2) Upload the file to course files (a quiz/ folder next to your HTML page works well). (3) Set type="csv" and filename="quiz/quiz-sample.csv" on the quiz. Lines starting with // are treated as comments and ignored.

Note: Only the eLC CSV layout is supported—generic spreadsheets will not parse. The component converts CSV rows into the same internal question format used for JSON, so all features (timer, retries, randomization, dropbox submission, grade sync) work the same way.

Basic (JSON, no timer):

<uga-quiz 
  quiz-id="demo-quiz"
  quiz-title="My Quiz"
  passing-score="70"
  type="local"
  filename="quiz/quiz-sample.json">
</uga-quiz>

  type="csv"

Note: The instructor creates the assignment (e.g. "Quiz Demo 2") in eLC and makes it visible to students (if hidden, submissions will not pass through). Use Text or File submissions and link it to a grade item. Place <uga-quiz-grade-sync dropbox-assignment-name="Quiz Demo 2"> (or dropbox-folder-id="folderId") below the quiz so instructors can run "Sync quiz grades to gradebook." JSON Question Format

The quiz component can load questions from a JSON file. The file must have a top-level questions array. Each question has id, type, question, points, correctAnswer, and optionally options, explanation, caseSensitive. See docs/QUIZ_JSON_FORMAT.md for the full format and examples.

Question types and correctAnswer format:

  • multiple-choice: options array, correctAnswer = index (0-based)
  • true-false: options ["True","False"], correctAnswer = 0 or 1
  • short-answer: correctAnswer string, optional caseSensitive
  • matching: options = match list, correctAnswer = object mapping choice text to match text
  • multi-select: options array, correctAnswer = array of correct indices
  • ordering: options array in correct order, correctAnswer = [0,1,2,...]

Steps to use a JSON file:

  1. Create a JSON file with a questions array (see quiz/quiz-sample.json, quiz/quiz10.json, or quiz/quiz20.json in this demo repo)
  2. Upload the JSON file to the same folder as your HTML page, or to eLC Public Files
  3. Add type="local" and filename="your-file.json" to the quiz component (filename only if same folder as the page, or full course-files path from Manage Files)

eLC CSV Question Format

The quiz component can also load questions from a CSV file in eLC's Question Import layout (the same one Brightspace generates when you export a question library). Use type="csv" and point filename at the file.

Each question is a block of rows. Required tags include NewQuestion (with question type), QuestionText, Points, and one of:

  • MC (Multiple Choice): one or more Option,<weight>,<text> rows. The option with weight 100 (or the highest weight) is treated as correct.
  • TF (True/False): TRUE,<weight>,<feedback> and FALSE,<weight>,<feedback>. Weight 100 marks the correct side.
  • SA / WR (Short Answer / Written Response): one or more Answer,<weight>,<accepted text> rows.
  • M (Matching): Choice,<id>,<text> and Match,<id>,<text> rows—the IDs link choice to match.
  • MS (Multi-Select): Option,<weight>,<text> rows. Every option with weight 100 is treated as correct.
  • O (Ordering): Item,<text> rows listed in the correct order; the component shuffles them at runtime.

Optional rows: ID, Title, Difficulty, Hint, Feedback, plus question-type extras like Scoring (matching) and InputBox (short answer). Lines starting with // are comments. See quiz/quiz-sample.csv in the demo folder for a working template covering all six types.

Steps to use a CSV file:

  1. Export questions from eLC (Question Library → Import/Export → CSV) or hand-author a file using quiz/quiz-sample.csv as a template.
  2. Upload the CSV to the same folder as your HTML page (or anywhere under course files).
  3. Add type="csv" and filename="your-file.csv" to the quiz component (relative path or full Manage Files path).

randomize-answers boolean false Shuffle the answer options within each question (multiple-choice / multi-select)

Question Types (JSON quick reference)

  • multiple-choice: options array, correctAnswer is index (0-based)
  • multi-select: options array, correctAnswer is array of indices, e.g. [0, 2]
  • ordering: options array (items in correct order), correctAnswer is [0, 1, 2, ...]. User arranges with up/down.
  • true-false: options ["True","False"], correctAnswer is 0 or 1
  • short-answer: correctAnswer is string, optional caseSensitive
  • matching: options array, correctAnswer is object like {"A": "Option 1", "B": "Option 2"}

Automating submission to the gradebook (instructor)

Instructors can send quiz results from the assignment into the eLC gradebook in one step:

  1. In eLC: Create the assignment (e.g. Quiz Demo 2), make it visible, set Text or File and All submissions are kept. In the assignment’s Grade (or Evaluation & Feedback) settings, link the assignment to a grade item in the gradebook (e.g. create or select a grade item so the assignment is tied to that column).
  2. Get the assignment folder ID: In eLC, open the assignment; the URL contains db= followed by a number (e.g. db=12345). That number is the dropbox folder ID.
  3. In your content: Place <uga-quiz-grade-sync dropbox-assignment-name="Quiz Demo 2"></uga-quiz-grade-sync> below the quiz (use the same assignment name as the quiz’s dropbox-assignment-name). Alternatively use dropbox-folder-id="12345" with the folder ID from the assignment URL (db=...). This component is visible only to instructors.
  4. When you want to update grades: Open the page as an instructor and click Sync quiz grades to gradebook. The component reads all quiz submissions from that assignment and writes each student’s score into the linked grade item. The most recent grade overwrites any current grade for each student. Run it whenever new submissions have come in.

There is no separate eLC setting to “automate” this—the one-click sync button is the automation. Students never write to the gradebook; only instructors trigger the sync.

Setup Requirements

  1. Assignment: Instructor creates an assignment in eLC (Assignments) with the same name as dropbox-assignment-name (e.g. "Quiz Demo 2"). Make the assignment visible to students (if hidden, submissions will not pass through). Set All submissions are kept. See docs/QUIZ_DROPBOX_SETUP.md.
  2. Questions: Use the provided quiz/quiz-sample.json (all six question types, JSON) or quiz/quiz-sample.csv (same six types, eLC CSV format). You can also create your own file in either format—JSON needs a top-level questions array; CSV must follow the eLC question-import layout.
  3. Upload Files: Place the JSON or CSV file in your course content area (same directory as your HTML page when possible, or set filename to the full path from Manage Files). Match type to your file: type="local" for JSON, type="csv" for CSV.
  4. Course Context: Component must be used within an eLC course page (for API access and assignment submission).
