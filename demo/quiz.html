Quiz Component

Embed formative quizzes directly in content pages. Supports multiple question types (multiple choice, multi-select, ordering, true/false, matching, short answer), auto-grading, immediate feedback, retry attempts, timers, and submission to an eLC assignment for tracking.

Use Case: Students can't take summative assessments until they've completed embedded formative quizzes (release conditions).

Demo: All Question Types and Features

This demo uses quiz-sample.csv, which includes all six question types: Multiple Choice, True/False, Short Answer, Matching, Multi-Select, and Ordering. The quiz below has all features enabled: timer (10 min with auto-submit), question randomization, retries, immediate feedback, and assignment submission.

File location: Download quiz-sample.csv . Place it in the same directory as your HTML (or set filename to the correct path).

Basic (CSV, no timer):

<uga-quiz 
  quiz-id="demo-quiz"
  quiz-title="My Quiz"
  passing-score="70"
  type="csv"
  filename="quiz-sample.csv">
</uga-quiz>

With assignment submission:

<uga-quiz 
  quiz-id="demo-quiz"
  quiz-title="My Quiz"
  passing-score="70"
  type="csv"
  filename="quiz-sample.csv"
  dropbox-assignment-name="Quiz Demo">
</uga-quiz>

All features (timer, auto-submit, randomize):

<uga-quiz 
  quiz-id="demo-quiz"
  quiz-title="Quiz: All Types & Features"
  passing-score="70"
  allow-retry="true"
  max-attempts="3"
  show-feedback="true"
  randomize-questions="true"
  time-limit="10"
  auto-submit="true"
  type="csv"
  filename="quiz-sample.csv"
  dropbox-assignment-name="Quiz Demo">
</uga-quiz>

Note: The instructor creates the assignment (e.g. "Quiz Demo") in eLC (Assignments) with All submissions are kept. Results are submitted to that assignment.

eLC CSV Format Support

The file quiz-sample.csv includes one question of each type (MC, TF, SA, M, MS, O). The component supports importing from eLC CSV format:

  • Multiple Choice (MC): Fully supported with option weights and feedback
  • True/False (TF): Fully supported
  • Short Answer (SA): Fully supported with multiple acceptable answers
  • Matching (M): Fully supported
  • Written Response (WR): Converted to Short Answer format
  • Multi-Select (MS): Fully supported (options with weight 100 are correct)
  • Ordering (O): Fully supported (Item rows define options in correct order)

How to use:

  1. Export questions from eLC in CSV format
  2. Save the file as CSV UTF-8 encoding
  3. Upload the CSV file to your eLC course files
  4. Use type="csv" and filename attributes

Properties

Property Type Default Description
quiz-id string '' Unique identifier for the quiz (used for tracking attempts)
quiz-title string '' Title displayed at the top of the quiz
type 'csv' 'csv' Load questions from eLC CSV file
filename string '' Path to the eLC CSV file. Use relative path (e.g. quiz-sample.csv) if the file is in the same directory as your HTML.
passing-score number 70 Percentage required to pass (0-100)
allow-retry boolean true Allow students to retake the quiz
max-attempts number 3 Maximum number of retry attempts
show-feedback boolean true Show immediate feedback after answering
randomize-questions boolean false Randomize question order
time-limit number 0 Time limit in minutes (0 = no limit)
auto-submit boolean false Automatically submit when time expires
dropbox-folder-id number 0 eLC assignment (folder) ID. If set, each quiz completion is submitted to that assignment for audits and tracking. Use an assignment with All submissions are kept. See docs/D2L_QUIZ_DROPBOX.md.
dropbox-assignment-name string '' Name of the eLC assignment (e.g. "Quiz Demo"). The instructor creates this assignment in eLC (Assignments); students only submit to it. Use the exact assignment title here so the component finds it by name. See docs/D2L_QUIZ_DROPBOX.md.

Question Types (in CSV)

  • multiple-choice: options array, correctAnswer is index (0-based)
  • multi-select: options array, correctAnswer is array of indices, e.g. [0, 2]
  • ordering: options array (items in correct order), correctAnswer is [0, 1, 2, ...]. User arranges with up/down.
  • true-false: correctAnswer is boolean (true/false)
  • short-answer: correctAnswer is string, optional caseSensitive
  • fill-in-blank: Same as short-answer
  • matching: options array, correctAnswer is object like {"A": "Option 1", "B": "Option 2"}

Features

  • ✅ Multiple question types (MC, Multi-Select, Ordering, T/F, Matching, Short Answer)
  • ✅ Auto-grading with immediate feedback
  • ✅ Assignment submission for tracking (instructor creates assignment in eLC)
  • ✅ Retry attempts with attempt limit
  • ✅ Timer support with auto-submit
  • ✅ Question randomization
  • ✅ Progress tracking
  • ✅ Detailed results review

Setup Requirements

  1. Assignment: Instructor creates an assignment in eLC (Assignments) with the same name as dropbox-assignment-name (e.g. "Quiz Demo"). Set All submissions are kept. See docs/D2L_QUIZ_DROPBOX.md.
  2. Questions: Use the provided quiz-sample.csv (all six question types, Google Drive) or export from eLC in CSV format and save as CSV UTF-8.
  3. Upload Files: Place the CSV in your course content area (same directory as your HTML page, or set filename to the path).
  4. Course Context: Component must be used within an eLC course page (for API access and assignment submission).
