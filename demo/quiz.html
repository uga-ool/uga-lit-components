Quiz Component

Embed formative quizzes directly in content pages. Supports multiple question types (multiple choice, true/false, matching, short answer), auto-grading, immediate feedback, retry attempts, timers, and completion tracking via gradebook integration.

Use Case: Students can't take summative assessments until they've completed embedded formative quizzes (release conditions).

Example: Load from D2L CSV Format

Import questions directly from D2L Brightspace CSV format. Export questions from D2L, save as CSV UTF-8, and load them into the quiz component. Supports Multiple Choice, True/False, Short Answer, and Matching question types.

File Location: Upload the CSV file to your course content area in the same directory as your HTML page, or use the full path.

Basic Code:

<uga-quiz 
  quiz-id="demo-quiz-csv"
  quiz-title="Quiz from D2L CSV"
  passing-score="70"
  type="csv"
  filename="quiz-sample.csv">
</uga-quiz>

With Gradebook Integration:

<uga-quiz 
  quiz-id="demo-quiz-csv"
  quiz-title="Quiz from D2L CSV"
  passing-score="70"
  type="csv"
  filename="quiz-sample.csv"
  grade-object-name="Formative Quiz 1">
</uga-quiz>

Note: The grade-object-name will be automatically created in the gradebook if it doesn't exist (requires instructor permissions). Results will be automatically saved to the gradebook when the quiz is submitted.

With External API (Recommended for Students):

<uga-quiz 
  quiz-id="demo-quiz-csv"
  quiz-title="Quiz from D2L CSV"
  passing-score="70"
  type="csv"
  filename="quiz-sample.csv"
  grade-object-name="Formative Quiz 1"
  api-endpoint="https://your-api.com/api/quiz/submit">
</uga-quiz>

Note: When api-endpoint is provided, quiz grades are submitted via an external API service instead of directly to D2L. This allows students to submit grades even without direct D2L write permissions. The API service can be set up in a separate project.

D2L CSV Format Support

The component supports importing questions from D2L Brightspace CSV format:

  • Multiple Choice (MC): Fully supported with option weights and feedback
  • True/False (TF): Fully supported
  • Short Answer (SA): Fully supported with multiple acceptable answers
  • Matching (M): Fully supported
  • Written Response (WR): Converted to Short Answer format
  • Multi-Select (MS): Not yet supported (will be added in future)
  • Ordering (O): Not yet supported (will be added in future)

How to use:

  1. Export questions from D2L Brightspace in CSV format
  2. Save the file as CSV UTF-8 encoding
  3. Upload the CSV file to your eLC course files
  4. Use type="csv" and filename attributes

Properties

Property Type Default Description
quiz-id string '' Unique identifier for the quiz (used for tracking attempts)
quiz-title string '' Title displayed at the top of the quiz
questions string (JSON) '' JSON string containing quiz questions (see format below)
type 'inline' | 'local' | 'csv' 'inline' Load questions from inline JSON, JSON file, or D2L CSV file
filename string '' Filename if type='local' (JSON) or type='csv' (D2L CSV format). Use relative path if file is in same directory.
passing-score number 70 Percentage required to pass (0-100)
allow-retry boolean true Allow students to retake the quiz
max-attempts number 3 Maximum number of retry attempts
show-feedback boolean true Show immediate feedback after answering
randomize-questions boolean false Randomize question order
time-limit number 0 Time limit in minutes (0 = no limit)
auto-submit boolean false Automatically submit when time expires
grade-object-name string '' Name of gradebook item for completion tracking. Will be created automatically if it doesn't exist (requires instructor permissions).
api-endpoint string '' External API endpoint for submitting grades (e.g., "https://your-api.com/api/quiz/submit"). If set, quiz grades will be submitted via this API instead of directly to D2L, allowing students to submit grades even without direct D2L write permissions.
allow-reset boolean false Allow manual reset of all attempts (for instructors/admins). Shows reset button.
auto-create-grade-object boolean true Automatically create the gradebook item if it doesn't exist. Requires instructor permissions.

Resetting Quiz Attempts

To allow a student to retake the quiz after reaching max attempts:

  1. Option 1 - Reset Button: Add allow-reset="true" to show a reset button (instructor only)
  2. Option 2 - Clear Gradebook: Go to Gradebook → Find the grade item → Clear the student's grade entry
  3. Option 3 - Browser Console: Clear localStorage using browser console (see documentation)

Note: Both the gradebook entry AND localStorage must be cleared for a complete reset.

See QUIZ_RESET_INSTRUCTIONS.md for detailed reset instructions.

Question JSON Format

{
  "questions": [
    {
      "id": "unique-question-id",
      "type": "multiple-choice" | "true-false" | "matching" | "short-answer" | "fill-in-blank",
      "question": "Question text",
      "points": 10,
      "options": ["Option 1", "Option 2", ...], // Required for multiple-choice, matching
      "correctAnswer": 1, // Index for MC, boolean for T/F, string for SA, object for matching
      "explanation": "Optional feedback text",
      "caseSensitive": false // For short-answer and fill-in-blank
    }
  ]
}

Question Types

  • multiple-choice: options array, correctAnswer is index (0-based)
  • true-false: correctAnswer is boolean (true/false)
  • short-answer: correctAnswer is string, optional caseSensitive
  • fill-in-blank: Same as short-answer
  • matching: options array, correctAnswer is object like {"A": "Option 1", "B": "Option 2"}

Setup Requirements

  1. Gradebook Item (Auto-Created by Instructors):
    • The gradebook item will be automatically created when an instructor/admin views the page (if auto-create-grade-object="true", which is the default)
    • Max points will be set to match your quiz's total points
    • Type will be set to "Numeric"
    • Important: Instructors should view the quiz page at least once before students take it, so the gradebook item is created
    • Students cannot create gradebook items (they don't have permissions), so auto-creation only works when instructors view the page
    • If auto-create fails or is disabled, you can manually create the gradebook item with the exact name specified in grade-object-name
  2. Export Questions: Export questions from D2L Brightspace in CSV format and save as CSV UTF-8.
  3. Upload Files: Upload the CSV file to your course content area (same directory as your HTML page).
  4. Course Context: Component must be used within an eLC course page (for API access and gradebook integration).

Gradebook Integration

When grade-object-name is provided, quiz results are automatically saved to the gradebook:

  • ✅ Auto-creates gradebook item when an instructor views the page (requires instructor permissions)
  • ✅ Points earned and total points are saved
  • ✅ External API Support: Use api-endpoint attribute to submit grades via an external API service, allowing students to submit grades even without direct D2L write permissions
  • ✅ Percentage score is calculated
  • ✅ Pass/fail status is recorded
  • ✅ Completion timestamp and attempt number are included in comments
  • ✅ Visual feedback shows save status (saving, success, or error)

Important Workflow:

  1. Instructor creates the quiz page with grade-object-name set
  2. Instructor views the page (this triggers auto-creation of the gradebook item)
  3. Students can now take the quiz and their grades will be saved automatically

Note: If a student tries to take the quiz before the gradebook item exists, they'll see a clear error message asking them to contact their instructor.
