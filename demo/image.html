Image Component

An image in a branded container with an optional caption. Clicking it opens a lightbox with zoom and pan, so detail in a diagram stays readable.

Add the component bundle before </body> — see Setup & Usage.

Basic usage

src and alt are the only required attributes. Add caption for a line beneath the image. Use a path relative to the page, or the full path from eLC Manage Files (right-click the file, Copy Path).

<uga-image src="image/demo_image.jpg" alt="Scatterplot of length against width, with a trend line through the long axis of the data cloud" caption="First and second principal components drawn through a correlated data cloud."></uga-image>

alt describes the image for someone who cannot see it, and the caption does not replace it. A chart needs its finding in the alt text, not just a title.

Responsive images

Give srcset several widths and sizes the display width, and the browser picks the file that fits the screen. Worth doing for large images, since eLC pages are often read on phones.

<uga-image src="image/demo_image.jpg" srcset="image/demo-400w.jpg 400w, image/demo-800w.jpg 800w" sizes="(max-width: 600px) 100vw, 450px" alt="Sample chart"></uga-image>

Turning off the lightbox

Add lightbox-disabled when the image has no detail worth enlarging, such as a small decorative graphic. The image then renders in the container but does not respond to clicks.

<uga-image src="image/demo_image.jpg" alt="Sample image" lightbox-disabled></uga-image>

Shadows

hover-shadow lifts the image on mouseover, which signals that it opens. For a fixed shadow instead, set shadow to base, deep or tinted; the explicit tints base--red, deep--red, base--blue and deep--blue also work.

<uga-image src="image/demo_image.jpg" alt="Sample image" hover-shadow></uga-image>
<uga-image src="image/demo_image.jpg" alt="Sample image" shadow="base"></uga-image>
<uga-image src="image/demo_image.jpg" alt="Sample image" shadow="deep"></uga-image>
<uga-image src="image/demo_image.jpg" alt="Sample image" shadow="tinted"></uga-image>

Appearance

The container is UGA red at 2px with rounded corners by default. Each part can be overridden, though changing them means stepping outside the standard look, so do it only when a page genuinely needs it.

<uga-image src="image/demo_image.jpg" alt="Sample image" max-width="600px" border-radius="0" border-color="#000000" border-width="1" padding="0"></uga-image>

Attributes

uga-image attributes
Attribute Type Default Description
src string empty Image path, relative to the page or the full path from Manage Files. Required.
alt string empty Alternative text. Required; it is the only description a screen reader gets.
caption string empty Caption shown beneath the image. Does not substitute for alt.
srcset string empty Comma-separated image paths with width descriptors, for example demo-400w.jpg 400w, demo-800w.jpg 800w.
sizes string empty How wide the image will display, for example (max-width: 600px) 100vw, 450px. Used with srcset.
placeholder string empty Image shown while the full image loads.
lightbox-disabled boolean false Render the image without click-to-enlarge.
hover-shadow boolean false Lift the image on mouseover, signalling that it opens.
shadow string empty Fixed shadow: base, deep, tinted, or a tint such as base--red.
max-width string 450px Maximum rendered width of the container.
border-radius number 15 Corner radius in pixels.
border-color string #ba0c2f Border color. Defaults to UGA red.
border-width number 2 Border width in pixels.
padding number 15 Space in pixels between the border and the image.
