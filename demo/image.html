Image Component

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Displays an image with optional caption in a styled container. Click the image to expand it in a lightbox with zoom and pan controls for viewing details. Based on instructional designer patterns with UGA brand styling.

Image path: Use a relative path (resolves from the page location) or the full path from eLC Manage Files (right-click file → Copy Path). This demo uses an image/ folder (e.g. image/demo_image.jpg). In eLC, use the full path from Manage Files, e.g. /content/enforced4/COURSE_ID/image/your-image.jpg.

Properties

Property Type Description
src string Image URL (required)
alt string Alternative text for accessibility (required)
caption string Caption displayed below the image
srcset string Optional. Comma-separated list of image URLs with width descriptors. Example: image-400w.jpg 400w, image-800w.jpg 800w. The browser picks the best size for the screen.
sizes string Optional. Tells the browser how wide the image will display. Example: (max-width: 600px) 100vw, 450px means full width on small screens, 450px otherwise.
placeholder string Optional. Low-res or blur placeholder URL to show while the main image loads
lightbox-disabled boolean When true, disables the expand-on-click lightbox behavior
max-width string Max width of container (default: 450px)
border-radius number Border radius in pixels (default: 15)
border-color string Border color (default: #ba0c2f UGA red)
border-width number Border width in pixels (default: 2)
padding number Container padding in pixels (default: 15)

Basic usage (relative path when image is in an image/ folder)

<uga-image src="image/your-image.jpg" alt="Description of image" caption="Optional caption text." ></uga-image>

eLC: use full path from Manage Files

<uga-image src="/content/enforced4/COURSE_ID/image/your-image.jpg" alt="Description of image" caption="Optional caption." ></uga-image>

With responsive images (srcset + sizes)

<uga-image src="image/photo.jpg" srcset="image/photo-400w.jpg 400w, image/photo-800w.jpg 800w" sizes="(max-width: 600px) 100vw, 450px" alt="Responsive photo" caption="Caption text." ></uga-image>
