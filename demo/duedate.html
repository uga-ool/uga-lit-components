Due Date Component

A table of everything in the course that has a due date: assignments, discussions, quizzes and content items, gathered automatically.

This component reads the current eLC course through the Valence API, so it only fills in when the page is viewed inside eLC. Add the component bundle before </body> — see Setup & Usage.

Basic usage

With no attributes it lists every item type that has a due date. Nothing needs configuring, because the course comes from the page URL.

<uga-duedate></uga-duedate>

Filtering by type

Pass types a comma-separated list to narrow the table. Useful on a page that should only talk about one kind of work, such as a discussion schedule.

<uga-duedate types="assignment"></uga-duedate>
<uga-duedate types="assignment,discussion"></uga-duedate>
<uga-duedate types="discussion"></uga-duedate>

Attributes

uga-duedate attributes
Attribute Type Default Description
types string assignment,discussion,quiz,content Comma-separated list of item types to include. Any of assignment, discussion, quiz, content.
