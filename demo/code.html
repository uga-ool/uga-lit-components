Code Block Component

A syntax-highlighted code block with a copy button. Highlighting comes from Prism, which the design system’s scripts.js already loads, so no extra script is needed.

Every code sample on these demo pages is this component. Add the component bundle before </body> — see Setup & Usage.

Inline code

Put the code between the tags and set language to the language name. The markup must be HTML-escaped, so write &lt; for <, otherwise the browser parses your sample as part of the page.

function greet(name) { console.log(`Hello, ${name}!`); } greet('Student');
<uga-code language="javascript">function greet(name) { console.log(`Hello, ${name}!`); } greet('Student');</uga-code>

Loading from a file

Set filename instead and the component fetches the file and shows its contents. Useful when the sample is a real file in your course files, because it cannot drift from the copy on the page.

<uga-code language="python" filename="examples/grading.py"></uga-code>

Languages

language takes any Prism language name. markup covers HTML and XML, and html is an alias for it. The name is shown as a label above the block, so it is also what tells a reader what they are looking at.

<uga-code language="markup">&amp;lt;p&amp;gt;Escaped HTML&amp;lt;/p&amp;gt;</uga-code>
<uga-code language="css">.cmp-button { color: #ba0c2f; }</uga-code>
<uga-code language="json">{ "title": "Module 1" }</uga-code>

Attributes

uga-code attributes
Attribute Type Default Description
language string empty Prism language name, for example markup, javascript, python, css or json. Also shown as the label above the block.
filename string empty Path to a file to load the code from, relative to the page. Overrides any content between the tags.
code string empty The code as a property rather than element content. Content between the tags is normally easier; this exists for setting the value from script.
