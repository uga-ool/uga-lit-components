Accordion Component

Expandable and collapsible content sections, with an Open All / Close All control above them. Useful for FAQs, course modules, or any page carrying more content than a learner needs at once.

Content comes from a JSON data file rather than from the page, so there is no markup to write beyond the tag itself. Add the component bundle before </body> — see Setup & Usage.

Basic usage

Set type="local" and point filename at a JSON file uploaded alongside the page in your course files.

<uga-accordion type="local" filename="accordion/accordion-demo.json"></uga-accordion>

Download accordion/accordion-demo.json to modify and upload to your own course files.

Data file format

The file holds a title and a data array. Each entry needs a title for the button and a body, which may contain HTML.

{ "title": "Frequently Asked Questions", "data": [ { "title": "How do I access course materials?", "body": "<p>All course materials are in the <strong>Content</strong> section of eLC.</p>" }, { "title": "When are assignments due?", "body": "<p>Due dates are listed in each module's overview page. All times are Eastern.</p>" } ] }

Loading from a program folder

Set type="program" and name the program to read the same file from a shared program folder instead of the current course.

<uga-accordion type="program" program="mba" filename="accordion-demo.json"></uga-accordion>

Attributes

uga-accordion attributes
Attribute Type Default Description
type string empty Where the data file lives: local for the current course, program for a shared program folder. Nothing loads until this is set.
filename string empty Path to the JSON data file, relative to the page.
program string empty Program identifier. Required when type="program", ignored otherwise.
