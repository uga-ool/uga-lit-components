Video Component

Single Video

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. See Setup & Usage for steps and JSON examples.

Embeds a single Kaltura video with customizable player. Use this method when you have one video to display. Logo/watermark is hidden by default.

Using video ID 1_icw0df6y (Faculty Profile)

Properties for Single Video

Property Type Description
videoid string Kaltura video entry ID (required)
playerid string Kaltura player ID (default: 1574196844)
includerating boolean Add rating component below video
topic-id string Optional. eLC content topic ID. Recommended when embedding inside a topic so completion events are reliably attributed (otherwise the topic is parsed from the parent URL).
enable-djinn boolean Show Kaltura Djinn Q&A panel (requires djinn-api-base and captions on the entry)
djinn-api-base string Base URL of the Kaltura Djinn service (no trailing slash), eLC-only with CORS
djinn-api-key string Optional; sent as X-Djinn-Api-Key if the Djinn server requires it
<uga-video videoid="1_icw0df6y" playerid="1574196844"></uga-video> <!-- With rating --> <uga-video videoid="1_icw0df6y" includerating="true"></uga-video> <!-- Kaltura Djinn (run uga-kaltura-djinn + LLM gateway; use only in eLC) --> <uga-video videoid="1_icw0df6y" enable-djinn djinn-api-base="https://djinn.example.edu"></uga-video>

YouTube Videos

Embed YouTube videos by setting host="youtube" and providing the video ID from the YouTube URL. For example, https://www.youtube.com/watch?v=yx3bxPfbdRM uses video ID yx3bxPfbdRM.

YouTube video: YouTube Demo

Properties for YouTube Videos

Property Type Description
host string Must be "youtube" for YouTube videos
videoid string YouTube video ID from the URL (e.g., yx3bxPfbdRM from youtube.com/watch?v=yx3bxPfbdRM)
name string Optional display name for the video (used in ratings and accessibility)
includerating boolean Add rating component below video
<!-- Basic YouTube embed --> <uga-video host="youtube" videoid="yx3bxPfbdRM" name="YouTube Demo"></uga-video> <!-- With rating --> <uga-video host="youtube" videoid="yx3bxPfbdRM" name="YouTube Demo" includerating="true"></uga-video>

Multiple Videos from JSON File

Embeds multiple Kaltura videos from a JSON data file. Use this method when you want to load multiple videos from a single JSON file. Perfect for course playlists or module video collections.

Example data file: Download videos/videos-demo.json to modify and upload it to your course files.

Note: This example loads multiple videos from videos/videos-demo.json

Properties for Multiple Videos

Property Type Description
type string Data source type: 'local' or 'program' (required)
filename string Name of the JSON data file (required)
program string Program identifier (for program type)
playerid string Kaltura player ID (default: 1574196844)
includerating boolean Add rating component below video
<!-- Multiple videos from file --> <uga-video type="local" filename="videos/videos-demo.json"></uga-video> <!-- With custom player ID --> <uga-video type="local" filename="videos/videos-demo.json" playerid="57494843"></uga-video>
