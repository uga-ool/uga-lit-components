Video Component

Embeds Kaltura or YouTube video. Kaltura embeds use Kaltura's Dynamic Embed method (a generated <div> plus KalturaPlayer.setup()), which is what Kaltura's own Share & Embed dialog produces.

Add the component bundle before </body>.

A single Kaltura video

Pass the Kaltura entry ID as videoid. Nothing else is required; the standard UGA Online player is used by default.

<uga-video videoid="1_icw0df6y"></uga-video>

Branded players

Set playerid to the uiConf ID, the number after uiconf_id/ in a Kaltura embed code. That is what carries program or college branding and end cards. Omit it for the standard UGA Online player (57494843). Each distinct player on a page loads its own player bundle, so prefer one player per page unless the branding genuinely differs — which is why this example is not rendered live here.

<uga-video videoid="1_icw0df6y" playerid="53568732"></uga-video>

Player IDs for the branded players currently in use. If the player you need is not listed, take the number after uiconf_id/ from that player's Kaltura embed code.

YouTube videos

Set host="youtube" and pass the ID from the YouTube URL. For https://www.youtube.com/watch?v=yx3bxPfbdRM the ID is yx3bxPfbdRM.

<uga-video host="youtube" videoid="yx3bxPfbdRM" name="YouTube Demo"></uga-video>

Multiple videos from a data file

Set type="local" and point filename at a JSON file of entry IDs to render a playlist from one tag. Useful for module video collections.

<uga-video type="local" filename="videos/videos-demo.json"></uga-video>

Download videos/videos-demo.json to modify and upload to your own course files.

Marking an eLC topic complete

Pass topic-id when the video should mark its eLC content topic complete. It is recommended whenever the video is embedded inside a topic, because without it the topic has to be parsed from the parent URL. This only does anything inside eLC, so it is not rendered live here.

<uga-video videoid="1_icw0df6y" topic-id="12345"></uga-video>

Collecting a rating

Add includerating="true" to show the rating component below the video. Leave the attribute off entirely when you do not want a rating. Ratings need eLC, so this example is not rendered live here.

<uga-video videoid="1_icw0df6y" name="Faculty Profile" includerating="true"></uga-video>

Attributes

uga-video attributes
Attribute Type Default Description
videoid string empty Kaltura entry ID, or YouTube video ID when host="youtube". Required unless the videos come from a data file.
host string empty Set to youtube for a YouTube embed. Leave it off for Kaltura.
playerid string 57494843 Kaltura uiConf ID, which selects the player and therefore the branding and end cards. Omit for the standard UGA Online player.
name string empty Video title, passed to Kaltura as entryTitle and used as the rating component's display name. Falls back to the video's Kaltura-reported name.
includerating boolean false Show the rating component below the video. Presence of the attribute enables it, whatever the value.
topic-id string empty eLC content topic ID. Recommended when embedding inside a topic so completion events are reliably attributed; otherwise the topic is parsed from the parent URL.
type string empty Where a multi-video data file lives: local for the current course, program for a shared program folder.
filename string empty Path to the JSON data file, relative to the page. Used with type.
program string empty Program identifier. Required when type="program", ignored otherwise.
