UGA Lit Components Demo

Welcome to the UGA Lit Components demonstration page.

This page showcases all available Lit web components designed for use in UGA's Brightspace (D2L) environment. Each component includes a live example, description, available properties, and sample code.

Note: Some components require D2L API access and will display placeholder data in this demo environment.

Table of Contents Component

Auto-generates a navigable table of contents from h2 and h3 headings on the page. Provides smooth scrolling navigation.

Note: The TOC above this section is a live example! It automatically scans all h2 and h3 headings on the page.

Properties

No properties required - automatically scans page for h2 and h3 headings.

<uga-toc></uga-toc>

Content Components

Accordion Component

Creates expandable/collapsible content sections. Great for FAQs, course modules, or organizing large amounts of content.

Properties

Property Type Description
type string Data source type: 'local' or 'program'
filename string Name of the JSON data file
program string Program identifier (for program type)
<uga-accordion type="local" filename="accordion-data.json"></uga-accordion>

Media Components

Video Component

Embeds Kaltura videos with customizable player. Supports single videos, playlists, and optional rating integration. Logo/watermark is hidden by default.

Note: Replace videoid with actual Kaltura video ID

Properties

Property Type Description
videoid string Kaltura video entry ID
playerid string Kaltura player ID (default: 1574196844)
type string Data source type for multiple videos: 'local' or 'program'
filename string JSON file for multiple videos
includerating boolean Add rating component below video
<uga-video videoid="1_abc123de" playerid="1574196844"></uga-video> <!-- With rating --> <uga-video videoid="1_abc123de" includerating="true"></uga-video> <!-- Multiple videos from file --> <uga-video type="local" filename="videos.json"></uga-video>

Code Block Component

Displays syntax-highlighted code with copy functionality. Supports multiple languages via Prism.js. Can load from file or inline code.

function greet(name) { console.log(`Hello, ${name}!`); } greet('Student');

Properties

Property Type Description
language string Programming language for syntax highlighting
filename string Load code from external file
code string Inline code content
<uga-code language="javascript"> const x = 10; console.log(x); </uga-code> <!-- Load from file --> <uga-code language="python" filename="example.py"></uga-code>

Setup & Usage

How to Use These Components in D2L

1. Upload the Bundle

Upload dist/js/uga-components.js to: D2L → Content → Manage Files → Public Files → /shared/PublicFiles/

2. Add to Your Page

<!-- Your components --> <uga-accordion type="local" filename="my-accordion.json"></uga-accordion> <uga-video videoid="1_abc123de"></uga-video> <!-- Load bundle at end of page --> <script type="module" src="/shared/PublicFiles/uga-components.js"></script>

3. Create Data Files (for components that need them)

Some components load data from JSON files. Upload these to Public Files and reference them by filename.

Example: accordion-data.json

{ "title": "Course FAQ", "data": [ { "title": "How do I submit assignments?", "body": "<p>Go to the Assignments page and click Submit.</p>" }, { "title": "When are office hours?", "body": "<p>Tuesday and Thursday, 2-4 PM EST.</p>" } ] }

Example: tabs-data.json

{ "data": [ { "title": "Overview", "body": "<p>This module covers...</p>" }, { "title": "Learning Objectives", "body": "<ul><li>Objective 1</li></ul>" } ] }

Example: circles-data.json

{ "data": [ { "figure": "85%", "caption": "Pass Rate" }, { "figure": "150", "caption": "Students Enrolled" } ] }

4. Testing Locally

npm run dev # Start development server npm run build # Build production bundle npm run preview # Preview production build
