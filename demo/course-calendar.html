Course Calendar Component

A course schedule table with week separators and row-type styling. It renders the table only, so the heading, intro and legend stay in your page HTML where you can word them freely.

Data comes from a JSON or CSV file in your course files. Add the component bundle before </body> — see Setup & Usage.

Basic usage

Set type="local" and point filename at a JSON file uploaded alongside the page.

<uga-course-calendar type="local" filename="course-calendar/course-calendar-demo.json"></uga-course-calendar>

CSV instead of JSON

Set type="csv" to use a flat CSV instead. Every row needs a weekLabel column, which is what the component groups on. A spreadsheet is usually easier to hand to a faculty member than JSON.

<uga-course-calendar type="csv" filename="course-calendar/course-calendar-demo.csv"></uga-course-calendar>

demo/course-calendar/course-calendar-template.csv in this repository is an empty starter with the right columns. The repository also has npm run quiz:csv-to-json for converting quiz CSVs, and the calendar accepts CSV directly.

Syncing with live due dates

Add sync-from-course and the component reconciles date cells against real assignment due dates in eLC, matching on dueTags[].folderId in your data. Dates then follow the course rather than the file, which is what you want when dates shift mid-term.

<uga-course-calendar type="csv" filename="course-calendar/course-calendar-demo.csv" sync-from-course></uga-course-calendar>

sync-due-status is a legacy alias for the same behaviour. Use sync-from-course in new pages.

Loading from a program folder

Set type="program" and name the program to read a shared calendar from a program template.

<uga-course-calendar type="program" program="mba" filename="course-calendar.json"></uga-course-calendar>

Attributes

uga-course-calendar attributes
Attribute Type Default Description
type string local Data source: local for JSON in the current course, csv for a flat CSV, program for a shared program folder.
filename string empty Path to the data file, relative to the page. Required.
program string empty Program identifier. Required when type="program", ignored otherwise.
sync-from-course boolean false Reconcile date cells with live assignment due dates from the current course, matched by dueTags[].folderId.
sync-due-status boolean false Legacy alias for sync-from-course.
course-id string empty Course OU to sync against, when it should not be taken from the page URL.
le-version string empty Valence LE API version override for sync mode.
