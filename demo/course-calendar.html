Course Calendar Component

Displays a table-only course calendar with weekly separators and row types.

Titles, intro text, and legend should be authored in page HTML outside the component.

For instructional designers: Add <script type="module" src="/shared/ugaonline/js/uga-components.js"></script> before </body>. Use filename for local/course-file JSON. Use sync-from-course (or legacy sync-due-status) to optionally reconcile date cells with live eLC assignment due dates by folder ID.

Basic calendar (static JSON)

CSV calendar (single flat file)

Use type="csv" with a flat file containing a weekLabel column on every row.

Optional live sync mode

This mode fetches assignment folders from eLC and updates matching date cells when dueTags[].folderId values are present.

Properties

PropertyTypeDescription
typestringlocal, program, or csv
filenamestringJSON file to load (required)
programstringProgram code used with type="program"
sync-from-coursebooleanOptional: synchronize date cells with live assignment due dates from the current course
sync-due-statusbooleanLegacy alias for sync-from-course
course-idstringOptional course OU override for sync mode
le-versionstringOptional LE API version override for sync mode

Usage

<uga-course-calendar type="local" filename="course-calendar-demo.json"></uga-course-calendar> <uga-course-calendar type="csv" filename="course-calendar-demo.csv"></uga-course-calendar> <uga-course-calendar type="csv" filename="course-calendar-demo.csv" sync-from-course> </uga-course-calendar>

CSV template: Start from course-calendar-template.csv. Required columns: weekLabel, rowType, date, day, event. Use pipe separators for multi-values: moduleItems, dueTags, and folderIds (aligned by position with dueTags).
