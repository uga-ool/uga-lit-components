eLC and Google Sync Component

An admin widget for moving course content between an eLC template course and a live course, and for exporting content to Google Drive.

Only administrators see the controls. Destructive actions and Drive export need configuration before they do anything, so the widget is safe to place before that work is finished. Full detail is in docs/ELC_GOOGLE_SYNC_WIDGET.md. Add the component bundle before </body> — see Setup & Usage.

Basic usage

Point the widget at a template course and a live course by their OU numbers. Inside eLC it shows a read-only preview of the template content, with module counts.

<uga-elc-google-sync template-ou="123456" live-ou="654321"></uga-elc-google-sync>

Previewing outside eLC

Add stub-mode to render the widget with placeholder data, which is how this page can show it at all. Never leave it on in a real course, because nothing it displays reflects the actual content.

<uga-elc-google-sync stub-mode template-ou="demo-template-ou" live-ou="demo-live-ou"></uga-elc-google-sync>

Who counts as an admin

By default the widget decides from the viewer’s eLC role. Use admin-role-names or admin-role-ids to name the roles that should qualify, as comma-separated lists.

<uga-elc-google-sync template-ou="123456" admin-role-names="Instructional Designer,Course Admin"></uga-elc-google-sync>
<uga-elc-google-sync template-ou="123456" admin-role-ids="104,115"></uga-elc-google-sync>

Google Drive export

Export needs an endpoint to upload to. Both values are deployment configuration rather than course content.

<uga-elc-google-sync template-ou="123456" drive-upload-url="https://example.org/upload"></uga-elc-google-sync>

Do not put a real token in course HTML. Anything in a page in Manage Files is readable by anyone who can open the page, so the upload credential belongs server-side behind the endpoint.

Attributes

uga-elc-google-sync attributes
Attribute Type Default Description
template-ou string empty OU number of the template course.
live-ou string empty OU number of the live course.
stub-mode boolean false Render with placeholder data so the widget can be viewed outside eLC. Not for use in a real course.
admin-role-names string empty Comma-separated eLC role names treated as administrators.
admin-role-ids string empty Comma-separated eLC role IDs treated as administrators.
drive-upload-url string empty Endpoint that receives the Drive export.
drive-upload-token string empty Token for that endpoint. Prefer handling credentials server-side rather than placing one in course HTML.
